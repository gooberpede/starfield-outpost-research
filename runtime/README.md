# Runtime Outpost Research

Reserved for explicitly authorized, bounded runtime research support. No native plugin, Papyrus script, injected observer, game modification, package, or deployment configuration is included.

A future runtime helper may establish ground truth, capture lifecycle events, or test a narrowly defined hypothesis. Distinguish observation-only design intent from the actual effects of instrumentation, hooks, extra scripts, timing changes, or injected code. Do not describe a helper as harmless without evidence.

Each proposal must identify the exact environment/build, third-party permissions/dependencies, observed state, intended output, actions, save risks, deployment owner, clean-profile/control requirements, stop/cleanup/uninstall procedure, and validation. Never modify a user's active/original save or shared tool deployment implicitly.

Record future mod integration leads with explicit status: observed internal mechanism, exposed interface, proposed integration, or validated integration. Runtime investigation is a first-class research outcome, not permission to implement a gameplay mod. See [AGENTS.md](../AGENTS.md) and [the charter](../docs/CHARTER.md).
