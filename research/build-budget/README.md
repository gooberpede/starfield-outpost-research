# L2 offline verification aid

[Report](../../docs/experiments/build-budget/report.md),
[review](../../docs/experiments/build-budget/review.md).

From repository cwd, using existing installed CPython:

```powershell
& 'C:/Users/User/AppData/Local/Python/pythoncore-3.14-64/python.exe' -B research/build-budget/verify.py --run verification01
```

Use a fresh alphanumeric run name. The verifier requires local L2 primary
receipts and protected source inputs; they are intentionally not distributed.
Reads: pinned native instruction exports, physical definition/source receipts,
menu ABC/timeline receipts, 19 saved scans (17 controlled plus two mature),
their source saves, HEAD/index and the governing brief. Writes: one exclusive
ignored JSON under `.local-work/l2-budget/`. Uses stdlib plus owned save framing,
Reader and free-space guard. No game, ActionScript/native execution, save/DB
mutation, new dependency/download, network or Git mutation. Both C:/D: must
retain 40,000,000,000 caller-available bytes.

It rehashes source inputs, independently decompresses selected originals/copies
in memory, walks BF masks/float offsets and compares exact primary bytes with
the scan. It checks the native locators, installed setting operands, actual
meter binding and original controls. A passing check is correspondence evidence,
not a replacement for primary native interpretation or independent review.

Local task helpers and their hashes are in the source ledger. l2-setup.py adapts
owned L1 protected baselines and E2ReadSession/Cr1Recon/TransitCalls under
SOR-P-0002; JVM is launched hidden, readOnly/noanalysis, writing only local
exports/settings/cache. l2-probe.py reads PE strings/constants; l2-defs.py reads
ESM/settings and searches installed development PSC for named budget leads;
l2-examples.py reads nine exact physical definitions and hashes the attachment.
l2-ui.py adapts owned C1 BA2 extraction and menu_abc.py to just WorkshopMenu;
l2-timeline.py independently resolves its named clip and counts timeline tags.
l2-save-setup.py adapts the owned L1 typed beacon/BF scan, using the existing
decoder scratch context/cleanup. l2-scan-setup.py adds bounded literal-instruction
inventory selectors to the owned native reader. l2-save-summary.py/l2-info.py
read local receipts only. l2-show.py displays selected local evidence only.
No helper executes decompiled game code or changes analysis state.

The local package exporter adapts the owned L1 exporter, constructs complete
and task-only Git text patches including untracked text, and applies/reverses
them only in disposable .local-work/review-patches trees. Workspace use is reverse-check only;
no staging, workspace application, branch or index changes. No third-party
code was copied into these aids. Bethesda primary payloads stay LOCAL-ONLY;
authored metadata and interpretation remain REVIEW-REQUIRED.
