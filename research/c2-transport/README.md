disposable lease input and separate output options to the `pex.py` CLI. All five
decoded member outputs and invalid-input controls reproduce after restoration.

original scope; no retirement or preservation-policy activation is implied.

Save52, not a tracker importer, general PEX tool or freight simulator.

Use existing CPython3.14 with `-B` from the repository root. No installation,
download, network access or target invocation. All acquired Bethesda payloads
stay ignored under `.local-work/c2-transport/`. Preconditions include the prior
accepted local S1/C1/E2 receipts and matching installed inputs. Caller-available
free space on **both C: and D:** must remain at least 40,000,000,000 bytes; each
entrypoint calls the owned fail-closed guard. New run labels use exclusive output
creation; do not overwrite evidence receipts.

`saved.py` adapts the maintainer-owned [C1 reader](../c1-cargo/save_case.py),
including only its native-backed Extra33 flag02/two-mod/mask00 case. It imports
owned S1 inventory and historical-save readers. Definitions/framing/guards
reuse [S1](../s1-storage/README.md) and
[save analysis](../../save-analysis/README.md). No third-party implementation
was copied, translated, downloaded or adapted. CPython/stdlib and existing
Ghidra/Temurin/Git are tools, separately credited, not new incorporated code.

Ignored acquisition utilities are also retained for review: `explore.py`
reads the owned E2 cache and installed ZIP/BA2 and extracts selected five PSC/
five PEX locally; `defs.py` rereads selected ESM fields; `pex_probe.py` preserves
the original parser exploration; `save_probe.py` preserves the wider reader
exploration; `save_summary.py` summarizes the selected save receipt.
`summary_save.py` retains its earlier missing-extra failure. `read_native.py`
splits local exports into local per-function text; it does not decompile itself.
`flightconstants.py` reads PE-mapped float bytes. Promotion/preparation scripts
write only these authored aids or ignored receipts; no game/DB/save mutation.

Native acquisition reuses the owned [OutpostRecon script](../../ghidra/scripts/OutpostRecon.java)
and unchanged owned E2ReadSession orchestration copied through C1. Exact command,
requests, exports and logs are ignored; existing analysis opened **readOnly /
noanalysis**, no import or symbol/type/comment changes. Exports preserve guessed
nonentries, capped symbol/instruction listings and decompiler warnings.
Request007's invalid instruction window and request036's13-selector admission
error ended their helper sessions; split/restarted queries preserve failures.
Only helper processes were started/retired, never the game. A90-minute helper
lifetime is a process bound, not a research stopping criterion.

The local package helper adapts the owned C1/S2 method: reads HEAD/index/text,
writes exclusive ignored complete/task-only diffs/manifests and disposable
.local-work/review-patches trees, verifies exact forward/reverse reconstruction and actual-tree
reverse applicability. It never stages/applies to the workspace or changes Git
refs/index. Raw saves/native/script payloads, databases and bulk receipts are
excluded. The review package records exact files and checks independently.
