[Frozen contract](../../docs/experiments/crew-lifecycle/plan.md), [report](../../docs/experiments/crew-lifecycle/report.md), [source pins](../../docs/experiments/crew-lifecycle/sources.csv). Run from repository root with existing `C:/Users/User/AppData/Local/Python/pythoncore-3.14-64/python.exe`. Stdlib and owned readers only; no install/network.

`scan.py` reads all 203 CR1 corpus receipts and fresh protected originals for all 23 nonempty E2 positives. It uses owned CR1 typed Actor/prefix/extra readers, CR2 ranked-tail reader and mature-save guarded streaming. It writes exclusive ignored per-save receipts and controlled scratch under `.local-work/cr3-lifecycle`, plus authored corpus/instance metadata CSVs. Existing receipts are reused explicitly rather than overwritten. Input hashes are checked before/after; unsupported branches remain UNKNOWN. It never writes a source save.

`verify.py --run NAME` hashes protected game/database/source inputs and HEAD/index/brief, physically rereads seven installed ESM records, independently selects saved part3 from body mask/queue, replays retained Actor bodies and tests wrong-version rejection. It writes an exclusive ignored verification receipt and authored generic-witness CSV. It checks grammar/integrity and selected definition grants, not runtime semantics or every Actor layout. New runs need fresh alphanumeric names. Imported helpers are pinned in the source ledger; no shared reader was changed.

Native work reuses owned `E2ReadSession.java`, `Cr1Recon.java` and `TransitCalls.java` from CR2, copied to ignored local native directory. CR3 adds read-only selectors for exact state-name string/xrefs, bounded actor/process virtual-call and field leads, and existing-code BB0/BA8 call inventory. These inspect existing listing/data/symbols only; offset matches are leads, not typed claims. Command/process receipts pin existing Ghidra12.1.2, Temurin21.0.12, EXE hash/base, readOnly/noanalysis flags and script hashes. Requests write exclusive TSV/done receipts; inspect caps, errors, decompile completion and actual worker exit. No game execution or database symbols/types/comments/bytes change. The local copied Java adaptation is retained/pinned; no proprietary decompilation is promoted into source files.

Both-drive 40,000,000,000-byte available-space guards and protected-source hashes apply. Hash mismatch/disk-query failure halts affected work; elapsed scan time is not failure. Native primary outputs, original paths/filenames, save bodies, installed game data and database remain LOCAL-ONLY. No copying to remote, staging, commit, deployment or publication follows.

Owned reuse under SOR-P-0002 credits CR1 current assignments/PEX/registry, CR2 selected ranks/part inheritance/effect consumers, E1 clocks/stacking, E3 manufacturing, P1 power and S2 remote scheduling/handle-resolution research. CPython/stdlib, existing Ghidra/Temurin and Git are tools. Bethesda native/data/scripts and maintainer save payloads have no new redistribution clearance.
