# C1 finite evidence aids

The [Cargo archive-access continuation](../evidence-access/README.md) adds explicit
disposable lease input and separate output options to `menu_abc.py`. Its complete
historical JSON output is reproduced after authenticated restoration. Original
acquisition/admission commands retain their original prerequisites and authority;
this does not activate retirement or a new preservation baseline.

[Frozen contract](../../docs/experiments/cargo-links/configuration-ui/contract.md),
[report](../../docs/experiments/cargo-links/configuration-ui/report.md),
[review](../../docs/experiments/cargo-links/configuration-ui/review.md).
Original GPL-3.0-or-later code; project-owned S1/P1/E2/S2 readers/methods reused
under the standing maintainer grant, with origin in the source ledger.

Run installed CPython3.14 with `-B` from the repository root. Standard library
and existing project readers only. Fresh alphanumeric `--run` names write
exclusive ignored receipts in `.local-work/c1-cargo/`; no overwrites. No game,
native invocation, DB/save/config/original-asset/Git mutation or network.

Native export uses unchanged project-owned OutpostRecon.java and the copied owned
E2ReadSession.java in the ignored native directory. Commands, ten request files,
done receipts, three discovery exports and logs remain local. Exact selectors
read existing analysis state under Ghidra readOnly/noanalysis; caches/logs and
exports are written outside the analysis project. Session stops normally using
its local stop file; no symbols/types/comments are added.

Early save01-03 ship-gap receipts, save01's overly broad player-reference queue
selection and guessed-prefix attempt are preserved history. Final code uses the
native flag-selected case rule, excludes static player from the selection and
does not silently treat unknown extras as empty. Final save06 adds targeted
terminals and direct/transitive graph controls. It is not a general inventory
extractor, save writer, logistics simulator or supported importer.

Local package export adapts the owned S2 helper; it writes ignored patches/
manifests and applies them only in fresh disposable .local-work/review-patches verification trees.
The supplied untracked brief is separate from task-authored files. Raw saves,
images, SWF/ABC/source/native output and analysis DBs remain excluded.
