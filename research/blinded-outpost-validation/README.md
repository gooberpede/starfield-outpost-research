Existing Python and Windows/.NET APIs are execution prerequisites. No package
installation or download is performed. Every run uses fresh output names. Only
task-owned disposable workers may be launched by qualification; no Starfield
launch, attach, observer deployment, save edit or new outpost is authorized.
Raw corpora, native receipts, copied runtimes and private logs stay local-only.
