# LO1 verification

`verify.py --run NAME` uses installed CPython3.14/stdlib and owned
`research/s1-storage/text_validation.py` plus
`save-analysis/scripts/inventory_historical_saves.py` for text validation and
the existing C:/D:40GB caller-available disk guard. Run from repository root.
NAME must be a new alphanumeric/hyphen receipt name.

It reads the hash-pinned local `.local-work/lo1-locations/` and inherited SD3
native/compiled/metadata receipts, selected installed PE bytes, protected source
hashes, supplied brief, HEAD/index and authored research. It writes only an
exclusive `verification-NAME.json` receipt in that ignored directory. It does
not execute native/ActionScript code, start a static worker, decode or load saves,
change sources/databases/configuration, install dependencies, stage or publish.
Missing local evidence fails; clean-checkout public reproduction is not claimed.

Acquisition/local packaging methods, immediate owned sources, exact hashes,
reads/writes and failures are retained in
[methods](../../docs/experiments/locations-outpost/methods.md) and the source
register. The verifier checks decisive source operations/identities and metadata
controls; passing it is not an independent semantic or rendered-game oracle.
