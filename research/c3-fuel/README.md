# Bounded C3 checks

Run from the repository root with the installed CPython executable and `-B`:

```
& 'C:/Users/User/AppData/Local/Python/pythoncore-3.14-64/python.exe' -B research/c3-fuel/verify.py --run verification01
```

The command reads `.local-work/c3-fuel/` acquisition receipts, the protected
baseline inputs, existing primary native evidence, installed-definition and
script derivatives, and Git HEAD/index. It writes one exclusive ignored JSON
receipt. It uses stdlib and project-owned readers; no network, dependency,
game/native execution, database edit, save change or Git mutation. Both-drive
40,000,000,000-byte guards apply. Existing stopped database/input hashes must
match before completion. Use a fresh alphanumeric run name.

The fixed cases check installed recipe/interval bytes, whole-recipe admission,
split supply and partial-cycle caps, two specified skipped-time examples,
actual mode/removal instruction locators, PEX method closure, saved stocks,
producer-row interpretation and graph membership. They are evidence/accounting
checks, not a generic fuel simulator or runtime semantic oracle.

Local acquisition helpers retain their own hashes in
[sources.csv](../../docs/experiments/cargo-links/fuel/sources.csv). `setup.py`
reads protected inputs/HEAD/index and writes baseline.json; `start_native.py`
starts existing Ghidra readOnly/noanalysis with the owned E2ReadSession exporter,
writing only ignored request/export/log files; its stop sentinel ends the reader.
`definitions.py` freshly reads installed ESM fields. `script_check.py` reads five
BA2 PEX members and five ZIP source members, matches earlier hashes and decodes
each PEX fully. `save_probe.py` adapts the owned C2 reader to follow only incoming
sources of selected cargo markers, with the owned E1 producer audit; it reads the
protected original and cleans decoded scratch. `show_native.py` only displays
existing exports. `update_indexes.py` writes authored documentation. `ledgers.py`
writes metadata CSVs and a source-ledger receipt. `package.py` adapts the owned C2
exporter, writing ignored patches/manifests and disposable D:/tools reconstruction
trees without staging. No acquisition helper is a product deliverable.
