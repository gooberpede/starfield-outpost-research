# BM1 offline verification

Purpose and authority: [plan](../../docs/experiments/construction-variants/plan.md),
[methods](../../docs/experiments/construction-variants/methods.md),
[original brief](../../docs/implementation-briefs/README.md#archive-lookup) (`implementation-briefs.zip :: docs/implementation-briefs/CODEX_BRIEF_SOR_BM1_construction_component_variants_dynamic_configuration.md`).
Read-only source analysis; no example mod or production importer.

`verify.py --run <fresh-alphanumeric-label>` runs from the repository root with
the existing CPython 3.14 interpreter and `-B`. Dependencies are stdlib and owned
save-analysis readers, already used by this project. It reads the pinned BM1
baseline, authored CSVs, local primary exports, installed main ESM and five
protected historical originals. It writes only one exclusive ignored
`.local-work/construction-variants/verification-<label>.json`; decoded scratch is
removed by the protected context manager. The 40 GB free-space guard applies
to both drives.

The checker independently rereads physical records/ordered fields and selected
saved envelopes and their reference queues, extra tag/mode/node-pair body bytes,
baseline preservation and native completion/provenance. Its DA, replacement and
owner assertions use the stored decoder output; it does not independently rebuild
extra-level queue consumption. The independent review separately sampled the
positive HIST-0210 doorway's DA source and 191/owner queue relationships against
the primary record. It does not invoke a native game
function, simulate geometry, measure gameplay or establish current load order.
Native VAs, ESM offsets, decoded save offsets, FormIDs and handle domains remain
separate. Failed checks abort and are not rewritten into PASS.

Local investigation helpers and their exact source hashes remain in the
[source ledger](../../docs/experiments/construction-variants/sources.csv).
Owned immediate methods include workshop_population/workshop_inventory,
inspect_outpost_definitions, stream_save, crew_extras, and the B1 read-only
static worker/patch exporter. This is source-informed project reuse under
SOR-P-0002, not third-party incorporation or a clean-room claim. Proprietary
decompiler, script, asset and save payloads remain LOCAL-ONLY.
