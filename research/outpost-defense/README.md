# DA1 offline research methods

[Frozen plan](../../docs/experiments/outpost-defense/plan.md),
[evidence/registers](../../docs/experiments/outpost-defense/evidence.md),
[review](../../docs/experiments/outpost-defense/review.md).

Run from repository cwd using existing CPython 3.14, assertions enabled:

```powershell
& 'C:/Users/User/AppData/Local/Python/pythoncore-3.14-64/python.exe' -B research/outpost-defense/verify.py --run NEWNAME
```

Requires local DA1 baseline, installed original files, protected historical
originals, completed native/definition/PEX/VMAD receipts and existing L2 UI
receipts. Raw material is deliberately not distributed with the checker.
It reads/hashes originals, physically rereads selected ESM fields and nine saved
records, checks native locators, complete PEX closure/branch operands, timer and
special-case bindings, UI method operands, literal saved damage and turret owner
joins. It writes an exclusively new ignored verification/failure receipt and
context-cleaned decoder scratch. No game, native invocation, source save/database
edit, install, network or Git mutation. Both drives retain 40,000,000,000 free bytes.
Passing assertions prove scoped correspondence, not actual gameplay or causation.

## Local acquisition and source lineage

All helper hashes are retained in the source ledger, under standing SOR-P-0002.
No decompiled game code is incorporated in authored helpers.

- `.local-work/da1-start.py` adapts owned L3/L2 intake and CR1 source selection.
  It rehashes protected inputs and HEAD/index, pins the supplied brief/image,
  scans existing development PSC members and starts an owned hidden read-only
  Ghidra reader with isolated settings/cache/logs. It never starts Starfield.
- `da1-acquire.py` and numbered revisions2/3/4 reuse owned esm_records,
  CR1 PEX and R1 BA2 framing. Read: installed ESM/Misc.ba2/ContentResources.zip.
  Write: exclusive local JSON and failed PEX witnesses. Final selected 38 PEX
  members close with corrected local `pex_da1.py`; earlier failures remain.
  No PEX/script execution, downloads or installed-source writes.
- `da1-vmad.py` is an original bounded script-property-prefix decoder. It reads
  local physical-field receipts and writes vmad01.json; type 7/17 corrections
  are documented. It does not claim complete quest-fragment/alias decoding.
- `da1-saves.py` / `da1-saves2.py` adapt L1/R1/CR1 typed-prefix/extra readers
  and the existing streaming decoder. They hash originals before/after, retain
  unsupported branches and write exclusive local scans. First pass covers four
  purpose-selected mature snapshots; second fresh HIST-0255 pass adds beacons
  and actual turret4C joins through native-backed E6 wire framing.
- Local `links_da1.py` adapts `research/r1-robots/links.py`: E6 is u32 count
  followed by count*(u32,byte), no reference-queue consumption. Other actor
  header/prefix/unsupported-state bounds are unchanged; it still returns only
  the first explicit4C block. E6's semantic payload meaning is not required or
  guessed merely to establish its exact framing.
- `native/E2ReadSession.java`, Cr1Recon and TransitCalls reuse owned L3/L2/R1
  read-only selectors. Numbered requests read existing strings/xrefs/functions,
  bounded instruction windows and data. Writes are local exports only. The
  native database is never analyzed or edited. Failed031 and restart logs are
  preserved; the replacement reader retires by stop sentinel.
- `da1-ledgers.py` writes authored numeric/hash CSVs from receipts; no proprietary
  bodies or private original paths are included in those CSVs. `verify.py` is
  the distributed checker described above. Packaging adapts the owned L1/L3
  exact-byte exporter with isolated forward/reverse scratch trees under
  `.local-work/review-patches/`; no workspace/index application or staging.

Dependencies are stdlib plus these owned project readers. Existing Ghidra/JDK,
Python and Git are recorded tools; their use does not clear proprietary outputs
for redistribution. Exact generated code helpers/native exports/raw saves stay
local; no production importer, attack simulator, mod or general combat tool is
delivered.
