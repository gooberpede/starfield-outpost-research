# Generated Exports — Local Only

Everything in this directory except this README is ignored by Git. Use it for local generated bulk output; use an external workspace or `.local-work/` for original saves, proprietary inputs, analysis databases, dumps, and private correspondence.

Do not force-add exports. Select only the minimum useful evidence, record original/derivative provenance and hashes, obtain the required rights/privacy/inclusion review, and place approved items under [docs/experiments/evidence/](../docs/experiments/evidence/README.md).

Ignored files are not backed up by Git and are not automatically safe to upload elsewhere. This directory contains no generated evidence at setup.
