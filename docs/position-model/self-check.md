# Reproducible position consolidation check

[Driver](../../save-analysis/scripts/check_position_consolidation.py) uses the
existing v1/v2 models, corpus extractor and cross-session decoder. No parallel
position algorithm or expected-output retuning. Run at repository root:

```powershell
& 'C:/Users/User/AppData/Local/Python/pythoncore-3.14-64/python.exe' -B save-analysis/scripts/check_position_consolidation.py --output .local-work/position-consolidation/check-NEW
```

Use a unique child name; it also reserves the unique corpus extraction name
`consolidation-check-NEW`. Requires installed CPython/stdlib, original local
manifests/archives/catalog/ESM and both sealed050/060 sessions at their documented
locations. No download, external tool execution or live access. Caller-available
free space must exceed 40,000,000,000 bytes on C: and D:. The driver validates
that guard before output and expensive subcommands; inherited readers retain
their allocation/integrity bounds. Writes only new ignored task receipts and
`.local-work/durable-center/consolidation-check-NEW/`; decoder scratch is removed
by the existing reader. `-B` prevents bytecode writes. Original saves, frozen
fixtures, captures, binaries, analysis databases and configurations are read-only.

The receipt records commands, Python identity, project source hashes, pinned
original v1/input/prediction hashes, counts and limitations. Failed subcommands
retain logs and a nonzero exit; no receipt PASS is produced after a failure.
Missing required archives/pins fail closed; absent optional **model site-cell**
returns UNKNOWN. Missing raw sessions are not optional and cannot become a pass.

Checks: all23 frozen v1 outputs unchanged; v2 center/residual bits and structural
cells; fresh23 input comparisons from the controlled/mature corpus; Save3 zero
selected records;19 mature zero compensation vectors;16 existing model tests
(relocation invariance, no-action, reflected/seam/negative floor, signed zero,
absent site and rejected identity/domain); cross-session decoder adverse tests;
81 sealed files and61 build-source pins plus protected Save25/26/installed PE;
all563,520 native records;40 native grid replays with nonzero XY and SOR-003
fine-to-middle carry. Raw schema decoding is existing independently authored
cross-session code, not the observer decoder. Grid arithmetic reuses the model;
the original native output remains the independent comparator.

Interpret counts separately:23 regression cases are not23 native oracles;
40 calls are two geometries on one planet. Exact hexadecimal equality tests
binary32 center/residual/translated XY; identity/cell/hierarchy checks are
structural, not proof of active ownership or historical frame authority.
Saved extraction shares project framing/decompression; it is a fresh re-decode,
not a second independently implemented save parser. Generic marker observations
remain separate. Save27/28 contextual landing evidence is retained in prior
reports, not added as invented position fixtures.

Actual run receipts, failures (if any), complete checks and independent decision
