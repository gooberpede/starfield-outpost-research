# Selected method reproduction contracts

2026-10-21. **Publication NOT CLEARED.** Availability tiers are independent of
scientific confidence, evidence completeness and rights approval.

**SOURCE AVAILABLE** permits inspection of identified source; **PROCEDURE
REPRODUCIBLE** requires qualified dependencies/instructions; **SYNTHETICALLY
QUALIFIED** requires an actually passed safe isolated case. **HISTORICAL /
UNAVAILABLE** identifies the precise missing replay input/environment. These
labels are scoped to a method and input class, never inherited by an entire study.

## Runnable representative: synthetic record framing

Purpose: challenge the exact R3 directory closure/count-width/bounds and diagnostic
prefix implementation used by Workshop/position/save studies. This is a framing
oracle, not an active-membership or native semantic oracle. Existing authored
sources are [reader](../../save-analysis/scripts/outpost_record_framing.py),
[dependency](../../save-analysis/scripts/stream_save.py) and
[test suite](../../save-analysis/scripts/test_outpost_record_framing.py).
Exact hashes, Python identity, invocation and actual output are in
[synthetic-qualification.json](../../research/evidence-data/publication-readiness-b3/synthetic-qualification.json).

Prerequisite: existing CPython 3.14.3, stdlib only; no download or package install.
Copy **only those three files** into a new caller-owned empty directory, then from
that directory use a locally chosen Python executable:

```text
<python> -I -B -c "import sys,runpy;sys.path.insert(0,'.');sys.argv=['test_outpost_record_framing.py'];runpy.run_path('test_outpost_record_framing.py',run_name='__main__')"
```

Before execution, source top-level imports were inspected: stream_save defines
classes/functions but does not decode at import; no corpus branch is requested.
Potential writes are three source copies plus the caller's chosen receipt/log.
`-I -B` excludes user-site/PYTHONPATH and bytecode. No game/save/tool installation,
network or process memory API is used. Fixed inputs are synthetic bytes constructed
in memory by six test methods. Outputs are unittest text, not decoded saves.
Expected: six methods pass, including independent arithmetic walking, truncation,
exact-closure failures, count widths and prefix/decoy cases; source-tree inventory
must be unchanged. Stop on nonzero exit, unexpected output files, changed copied
source or a failed drive guard. Keep receipts; no historical evidence cleanup.

**Actual result: six tests PASS**, Python 3.14.3, exit 0; copied file hashes and
file inventory unchanged. The isolated tree is under project
`.local-work/review-patches/b3-synthetic-krx6_2fz/`; local execution receipt is
`.local-work/b3/synthetic.json`. A curated tracked receipt contains no raw inputs.
Its derivation field records the original receipt hash and exact newline/JSON
transformation; `.local-work/b3/synthetic-derivation.json` records both input and
output hashes. Original captured bytes remain unchanged.
Tier: **SYNTHETICALLY QUALIFIED**, solely this synthetic entrypoint. Real corpus
mode was not run. No full decoder, live observer or native ABI qualification is
implied.

The archival invocation pattern is syntax documentation, **not an instruction to
replay in place**. Historical scripts can use `Path.cwd()` or `__file__.parents`,
fixed study aliases and local inventories. Moving source does not fix these
assumptions. Use source inspection now; a future real reproduction needs a separately
prepared disposable layout, verified inputs, reviewed output behavior and the
relevant experiment authority. Read-only native exporters can write large
proprietary output and can affect analysis-process state; no claim of a universally
non-intervening tool is made. SOURCE AVAILABLE is the honest tier for these files.
