# Current outpost research roadmap

Start with a question below. The guides explain observed or mapped behavior,
what the save retains and what needs a current engine decision. The technical
references link to exact fields, methods, original reports and reviews.
See the [first-release scope](first-release-scope.md) for selected tiers and
deferrals, [evidence access](reference/evidence-access.md) for prerequisites
and [history](history/README.md) for supersessions and negative results.

The principal native and installed-definition baseline is **Starfield
1.16.244.0**. Historical sample versions have separate provenance.
**Publication is NOT READY / NOT CLEARED.**
