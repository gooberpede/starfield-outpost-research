## Optional post-publication VII-b study

If separately authorized, an independently conducted live study of approximately
30 samples could adapt the qualified D5AS acquisition protocol. It would first
establish the resident source and a compatible geometry frame, then seek repeated
full-geometry comparisons against the predicted fixed-input mask-0 and mask-2
classes. It has no current execution authority and sits outside first-release
requirements. Geometry-reference matches would address observed geometry.
Generating masks, IID sampling and construction-winner probabilities require
their own evidence. [D5AT candidate assessment](../../experiments/resource-retained-population/d5at-candidate-assessment.md)
