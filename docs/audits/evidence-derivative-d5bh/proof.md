## Omission and integrity rules

- Dropping other holders defeats unique geography. A hidden target is possible
  even when a visible target qualifies. The projection preserves all holders
  and all source transitions. The alternative-geography control is rejected.
- Dropping a non-target Grid clear changes the epoch bridge. Each original
  sequence appears once and the relevant scopes are replayed. The reviewer
  compared the full projected spine to the original wire and challenged a
  missing/reordered event, wrong interior epoch and same-owning-Grid fence.
- Dropping or repointing a single content ending can leave old geometry alive
  despite exact normalized equality. The full lifetime wire is copied and
  checked directly. An independent control repointed an ending and recomputed
  frame and flush CRCs, then was refused by the lifetime result.
- Event kinds outside the retained reducer set keep only sequence, kind and
  QPC. This preserves the sequence domain while declining assertions about
  winning requests, per-call admission, placement or complete engine activity.
  No original core CRC equality is claimed for the projection.
- Descriptor padding values are withheld. An injective per-episode token
  preserves the original equality partition for all three construction
  record types. Zero padding for all records would erase a real distinction.
  Region header padding has no role in the normalization and is replaced with
  zero bytes in the target projection. The exact normalized bodies are copied
  separately.
- Normalized hash equality is a byte pin. The oracle compares the entire
  recomputed byte arrays, and the byte tests deliberately change the fourth
  point word. Process, original capture, source and frame are checked before
  accepting that equality.

The candidate contains exact expired process/address operands so equality,
receiver adjustments and native pointer-domain joins can be checked. Do not
reinterpret these fields as saved IDs, file offsets, FormIDs or addresses
portable to another build. Site RVAs and source pins qualify N244 only.
Disclosure review is file-specific and pending. The smallest prospective
maintainer decision is whether to select these exact reviewed bytes at this
bounded tier for rights review and B6, or retain the episode claims as
attributed historical findings.
