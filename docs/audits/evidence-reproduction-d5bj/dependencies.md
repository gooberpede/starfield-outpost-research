All PE page recipes identify preferred virtual addresses and enforce PE32+
section backing and protection. Whole-file SHA-256 binds these pages to the
original build. Numeric data pages become read-only. The geometry RNG state
pages remain writable inside the fixture. The host binds only the declared
imports and callbacks, so a missing path faults or refuses instead of loading
engine services. Native exceptions invalidate the disposable run. There is no
privileged isolation promise. Every source and asset input is read-only.

This work uses authored project and maintainer-owned methods under
SOR-P-0002, Bethesda reader-supplied inputs, CPython and the system ABI/CRT.
Game pages, archive members, original receipts and native captures remain
local. D5AS compares canonical-body bytes, with resource sorting and the
first 21 native header bytes per region. D5AK/D5AL include a different
envelope. Neither candidate route grants redistribution of the underlying
game or original captures.
