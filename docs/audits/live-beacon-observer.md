## Evidence durability, bounds and instrumentation health

Each unique settled request makes one snapshot directory, begin record, independently flushed raw files, append-only flushed JSONL and separately durable completion marker. Raw records preserve root, pointer, field/source provenance, extent, SHA-256 and timestamps. Candidate transforms include exact binary float32 bytes; scalar JSON floats use round-trip precision and nonfinite strings. Process creation, PID, actual worker TID, ASLR base, DLL/executable hashes and startup native module inventory identify execution. Startup module paths are private. No atomicity or native ownership is claimed.

Healthy independent collectors continue after null, unreadable, unknown branch, changed identity, cyclic chain or malformed extent. `NOT_OBSERVED`, `UNREADABLE`, `UNSUPPORTED`, `UNEXPECTED`, `QUERY_FAILED` and `CAPTURE_PARTIAL` are the classification vocabulary; QUERY_FAILED is reserved because this version makes no native query. Unknown fields remain raw/unclassified; no zeros masquerade as decoded fields. Scientific completeness is independent of the acquisition marker and target survival. No new live observation exists in this package.

Disk checks use caller-available bytes from GetDiskFreeSpaceEx on **both C: and D:** before capture and each write chunk. Exactly40,000,000,000 passes; less on either volume or failed query stops. Per-write chunks are64KiB; native pool chunks4096slots. These are buffer/scheduling sizes, not evidence caps. No fixed elapsed-time, file-count, error-count or evidence-volume cutoff. A full-pool scan is finite; chains track visited addresses; table arithmetic rejects overflow. Requests are consumed once and no collector retries a failed read indefinitely. STOP is cooperative between writes and never terminates Starfield. Writer/hash/flush or loaded-code-integrity failure stops instrumentation without fabricating complete evidence. At low disk a failure marker may itself be unavailable; preserve the existing journal and orphan raw files.

Residual safety limits: a corrupt but plausible acyclic chain/table length can cause excessive work before an unreadable page, STOP or the disk guard. Source inspection cannot qualify live object lifetime or meaning. Worker acquisition does not intentionally pause the game but consumes CPU/I/O and races normal execution. Memory-copy failure does not crash-suppress the game; no exception handler or debugger is installed. Teardown is cooperative; DLL remains resident until user exits normally. These risks require critical review before live use.
