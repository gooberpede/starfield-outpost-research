## Independent challenge and correction

The first exact-snapshot review independently reconciled 238,272 original
frames, all projected fields and both custody forms. It found four in-memory
mutations that the first semantic replay accepted. They moved final release
before store, ownership after the protected miss, a layer provider before
readiness, and a visited result before its own selection. The revised verifier
checks the same-thread lock enclosure and observed typed-stage progression,
including shared release before bypass and later layer readiness/service.
Each challenge now has a deterministic control. The ZIP bytes are the same.

The first scratch diff application used Git's default Windows conversion and
produced CRLF output. A fresh scratch export with explicit
`core.autocrlf=false` applied and reversed both patches byte-for-byte. The
repository configuration and index were untouched.
