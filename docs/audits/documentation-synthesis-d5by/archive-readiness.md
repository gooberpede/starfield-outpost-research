# 7B archival readiness

Default for the future assignment is lossless archival of implementation
briefs and administrative audit narratives. D5BY supplies navigation,
a scope register, a reader method contract, and lookup pages. 7B owns
archive membership, safe extraction, exact container/member verification,
updates to indexes and rechecking code and documentation consumers.

## Proposed loose exceptions

**No administrative narrative or brief is proposed as a loose exception.**
Scientific reports and reviews need stable reader routes. File category
depends on content and consumers, including the RC1 research under the
audit directory. Relocation preserves those sources without retaining an
administrative document solely for an inbound link.

Machine operands are a separate category. The selected original readers
need `docs/audits/release-assets-d5bf/release-assets.json`; the Workshop
projection checks `docs/audits/evidence-access-d5bx/assets.json`; the
N2 verifier reads `docs/audits/evidence-derivative-d5bi/manifest.json`.
The compatible-source copy and any method locator must preserve the exact
operand identity and expected path or qualify a changed source closure.
An index entry cannot substitute for a runtime file open. Keep these
machine files available to their consumers or qualify relocation under 7B.
D5BY's validator also reads the inherited proposal, readiness and overlay
JSON files at their current paths.

## Migration acceptance

Use the [reader dependency census](reader-dependencies.csv) for the bounded
D5BY reader surface. In addition, recensus every eligible path, retained
document, fragment, plain-text locator and runtime path before changing
the actual tree. Inspect fixed paths and constructed paths in method code,
source pins, tests, manifests and publication recipes. Use exact original
path and case in the future member index. Link current users to the stable
replacement and history readers to the archive index with the exact member
path as text. A hash identifies the archived member and cannot replace the
retrieval and extraction check. D5BY does not establish any ZIP location.
