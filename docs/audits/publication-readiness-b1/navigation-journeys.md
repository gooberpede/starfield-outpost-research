## Checks, receipts and exclusions

Local `.local-work/b1-navigation/verify.py --run <unique-name>` uses installed
CPython standard library and Git; no installation, network or third-party analysis
tool runs. Reads: Git-visible documents and named baseline/original text. Writes:
ignored JSON/link/status receipts and review diffs under `.local-work/diffs/`, plus
standalone reconstruction trees under `.local-work/review-patches/`. No index,
ref, game, save or analysis-database write. Each run preserves earlier receipts.
`GIT_CEILING_DIRECTORIES` stops discovery at `.local-work/` in scratch. The
40,000,000,000-byte caller-available guard on C: and D: is checked before packaging.

The checker classifies inline/reference-definition/HTML targets, checks file case
and ordinary heading/HTML fragments, records external URLs and local-only paths
separately, and builds reachability using proposed-tree edges only. It strips
fences but is a bounded parser, not a complete CommonMark implementation. It checks
all changed Markdown for strict UTF-8, BOM, newline style, whitespace, table shape
and known malformed-prose/encoding sentinels. Preserved historical body prose is
reported separately rather than silently corrected; B2 remains the full prose audit.

Matrix checks require per-row pin/version/evidence/exclusion/proposal cells and
NOT CLEARED text; they do not independently establish the truth of a build pin.
Roadmap checks require each major domain's current report, technical/evidence
reference and independent review. Nine journeys check actual graph edges.
Historical original “All OPEN” and next-stage text is retained beneath explicit
current-entry wrappers; the publication opening is corrected without changing
its release gate. The permission link now goes to the actual register/table row.

Patch inventory equality, exact forward/reverse reconstruction and actual-tree
reverse applicability are checked without staging. Complete includes the unchanged
supplied brief; task-only excludes it. Protected Git-visible originals outside the
allowed edit list, supplied brief, HEAD and index are rehashed before/after. This
does not claim a fresh hash census of installed game/save/database bytes outside
the documentation read/write set; none was operated on.
