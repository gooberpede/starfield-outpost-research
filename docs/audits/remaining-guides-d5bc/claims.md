# Claim-to-evidence crosswalk

[D5BC questions and acceptance contract](../../implementation-briefs/CODEX_BRIEF_SOR_RG2_D5BC_Remaining_Subsystem_Guides_and_Collection_Consistency.md)
govern this synthesis. STATIC describes a definition, script or native path.
SAVE describes sampled decoded bytes and qualified joins. Derived results use
stated inputs and conditions. The assignment supplies no new RUNTIME evidence.
The native baseline is retail 1.16.244.0, EXE SHA-256
`7e9adb1414a8e1b325e5e1f097b9b17b78deb7eebeda37a333351a43a60f9d28`,
main ESM SHA-256
`1dabed00c3f4282dd3bb54d2e9601e40b577d8742d078b7ccef203adbfef0da7`
where cited. Historical originals and other inputs retain their source pins.
Addresses in native reports use preferred static VA unless marked otherwise.

**Access key.** T means tracked authored evidence, locator or review text
available to inspect in this checkout, subject to the separate release gate.
D means a derivative check can run from tracked inputs. P means the decisive
primary witness remains protected. Each P below is a **PUBLICATION DEPENDENCY
— EVIDENCE ACCESS PENDING** for independent access to that claim's primary
evidence. An original report's hash or private export locator does not resolve P.
