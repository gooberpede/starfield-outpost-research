## Structured row reconciliation

The bounded retained-export pass accounted for all 169 previously unresolved
structured rows. The pass checked source SHA-256 values and record headers in
35 retained text exports. It identified 141 exact entry headers, 27 windows
inside a different function section, and one named receiver census without
an entry address. All 27 windows identify an enclosing catalogue entry.
The catalogue retains the window's source coordinate and its separate owner
in `containing_entry_va`. The census retains its original identifier in the
excluded locator table. No raw instruction or decompiler text is included.
[Boundary receipt](../../../research/function-catalogue/residual-boundaries.csv).

The receipt joins the original ledger `path` and physical `line` to
`source_va`, `export_sha256` and, where present, `header_line` and `entry_va`.
`entry` verifies the nominated VA. `contained` identifies the function section
without turning the selected instruction into an entry. `no-header` preserves
the named census. The verifier requires every receipt row to match a scanned
source row. Relevance is assessed separately against the original mechanism
report or a source-specific claim in the original range ledger.
