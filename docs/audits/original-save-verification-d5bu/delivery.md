# D5BU delivery and editorial checks

The full patch covers all uncommitted authored text, including the unchanged
supplied brief. The task-only patch covers the entire D5BU implementation and
audit, including the first checkpoint and resumed corrections, with that brief
excluded. All files were untracked at the original D5BU intake apart from the
existing tracked research tree. Existing tracked files remain byte-identical.

Final patch names use the required `.local-work/diffs/d5bu-final-complete.diff`
and `.local-work/diffs/d5bu-final-task-only.diff` convention. Reconstruction
trees use exclusive caller-owned directories beneath
`.local-work/review-patches/`. Git discovery stops at `.local-work/`.
The exporter compares patch inventories with actual tracked/untracked status,
reconstructs exact working-tree bytes and reverses to the prior empty
new-file inventory. Actual-tree reverse applicability is checked read-only.

The original earlier patch placement beneath the task scratch directory was
a workflow deviation. Its artifacts remain historical. The corrected final
patches and manifest use the required paths.

The editorial review covers every new Markdown file, source comment/docstring
and machine-record label. Generated hashes and IDs receive identity/schema
checks. The screen is followed by manual reading for qualifications, notation,
input/output promises and consistency with the receipts. Historical checkpoint
prose and first-review verdict retain their dated incomplete state. The current
README and matrix describe the resumed results.

Ignored exclusions remain original ZIPs and members, saves and decoded buffers,
images/maps/installed data, source-copy trees, recovered historical raw receipts,
private open-file logs/paths, temporary test files and patch replay trees.
Their receipt hashes and local relative locators support review. They receive
no publication clearance through this delivery.

The final independent reviewer receives the original brief, user correction,
all primary receipts and failed controls, the source/effects/protection manifests,
the corrected patches and exact-file inventory. A substantive correction returns
the same assignment to testing and review.

at the decimal PNDT payload field. That offset is decimal by the original
fixed-Lab evidence convention, so the warning is a reviewed notation exception.
