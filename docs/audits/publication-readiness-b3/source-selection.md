# Claim-led source selection

2026-10-21. **REVIEW-REQUIRED; publication NOT CLEARED.** The starting scope is
the [proposed B1 matrix](../publication-readiness-b1/claim-build-matrix.md), including
its continuation table. B3 determines method access; it does not approve that
matrix for release or change a scientific claim.

[source-selection.csv](source-selection.csv) retains individual original ledger
citations, literal/canonical paths, historical and freshly observed hashes,
selection decision, ownership boundary, destination and exclusion rationale.
[promoted-sources.csv](promoted-sources.csv) gives exact bytes/hashes, origin,
destination, direct import/API dependencies, path assumptions and inspection for
every selected local origin. Origin and destination hashes are equal. Deduplication
is by exact bytes, never basename. Absolute Windows paths are historical metadata,
not requirements imposed on the reader.

The selected sources are project-authored methods identified by the cited
experiment ledgers and their source-informed owned-method declarations, under
SOR-P-0002. This does not infer authorship merely from repository ownership.
Native exporter Java source calls installed Ghidra APIs; it contains exporter
implementation, not emitted decompilation. No installed Ghidra/JDK code is copied.
The screening checked imports, output calls, long literals, path assumptions,
credential patterns and method lineage. Finite EditorIDs, numeric selectors and
opcodes are algorithm inputs; no game byte dump or script implementation is
embedded. This inspection is not B4 rights clearance.

All selected native-export origins in the manifest retain exact historical
versions; byte-identical E2/Cr1/Transit implementations are shared across citations.
They need a lawful independently prepared imported program and the original
selector/request context. A RobotFields dispatch is an optional selector dependency,
not an assertion that its implementation is supplied in every archived variant.
No B3 contract qualifies that optional selector. Earlier native observations and
their publication status stay unchanged.

Five classifications are intentional. Existing maintained readers remain in their
current directories. Unique later methods are **archival/source available**, not
new maintained products. Essential one-off arithmetic/joins are retained with
their historical limitations. Generated activators, snapshots and package/index
writers stay local; their receipts preserve packaging history without making them
necessary to recompute an algorithm. Third-party tools, installed data and raw
outputs are external/protected, separately governed by B4. Deferred reconnaissance
is listed with exact current identity; it is not silently presented as supplied.

This is a source access determination for every B1 domain, not a claim that all
historical experiments can be rerun. [Method contracts](method-reproduction.md)
identify the runnable synthetic subset and remaining exact-replay dependencies.
No dependency installation or automatic download is proposed. Existing
[B0 retention](../publication-readiness-b0/local-work-retention.md) remains binding;
neither rejection nor duplication is deletion approval.
