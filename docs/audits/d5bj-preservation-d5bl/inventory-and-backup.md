# Private working backup

The new ignored copy under `.local-work/d5bl/backup-01/` holds **360 files,
35,770,957 bytes**. All 286 historical D5BK files matched the prior size and
SHA-256. The 74 additions are supporting files from named lineages. The
current D5BJ root contributes the same 250 members as the D5BK inventory.

The inventory retains each source-relative name under the backup root.
Original ZIPs and staged copies remain distinct even where their bytes agree.
Tracked source remains identifiable in Git. Full review exports would
duplicate thousands of checkout paths. The copy selects the receipt-pinned
D5BJ methods plus the staged-input controls. In each of the five named
isolation exports, all 3,959 omitted source files matched the exact
pinned Git archive byte-for-byte. The private exclusion receipt records
each export's selected and omitted counts. The copy also excludes old
patch-application trees and unrelated D5AQ attempts. It excludes
whole native-export and analysis trees, game-install files, save libraries,
unrelated local work and the D5BL destination. The upstream D5S, D5AE and
D5AM proofs are referenced by their existing source IDs. This copy covers
the selected D5BJ working record and associated receipt dependencies.

The primary pass checked pre-existing identities, rejected reparse paths and
case-insensitive mapping collisions, created each destination exclusively and
rehash-checked both disk files. The preflight caller-available values were
90,892,025,856 bytes on C: and 77,456,572,416 bytes on D:. The check reserved
128,000,000 bytes above each 40,000,000,000-byte floor, plus the D: payload.
Post-copy values were 90,891,366,400 bytes and 77,419,151,360 bytes.

The separate data-only verifier enumerates files and directories from the
destination, validates containment and the exact member set, compares every
source and destination as bytes, and verifies both the new and applicable
historical pins. The primary verifier returned 360 files, 66 directories and
286 D5BK matches. [Independent result](review.md)

`inventory.json`, `copy-progress.jsonl`, `copy-result.json`,
`verification-primary.json` and the independent receipt are local under
`.local-work/d5bl/`. The inventory includes exact source/destination
locators, class, lineage, size and SHA-256. The new audit helpers operate on
existing bytes and create only local audit outputs. They use Python's standard
library and require no game installation.

The copy shares the repository and volume with the originals. It reduces the
risk of accidental loss of selected files. Disk failure, common corruption
and directory-wide deletion can destroy both copies. D5AW allows disposal of
all `.local-work/` after publication, so independent public evidence requires
a cleared route that survives that disposal. [Retention decision](../../DECISIONS.md#d5aw-local-working-evidence-and-publication-independence--2026-11-07)
