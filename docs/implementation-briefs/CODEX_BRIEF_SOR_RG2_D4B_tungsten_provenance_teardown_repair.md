The captured Tungsten's consumption-time source anchor and frame correspond to an existing source in the frozen D3 input set, but D3's projected generator resource list for that source excludes Tungsten. The scientific receipt was already durable and accepted; the teardown fault is a **separate, unresolved engineering defect**. Preserve all original evidence and failure records.
