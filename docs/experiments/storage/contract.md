# S1 frozen contract and execution boundary

[Original invoked brief, section 6](../../implementation-briefs/CODEX_BRIEF_SOR_S1_storage_inventory_eligibility_runtime_save.md)
is the frozen completion contract; no criterion is replaced by this implementation
account. [Review matrix](review.md) retains all eight criteria.

Question: storage-bearing outpost definitions, admission/capacity, reference-level
local-link capability, native/save correspondence and limited ship/cargo roles.
Competing models include item-count versus weight capacity, single-form versus
mixed contents, UI-only versus native endpoint exclusion, and physically local
recipe inputs versus incoming-source inventory consumption.

Allowed actions: read/hash installed executable/ESM/development source and existing
native exports, export existing Ghidra state readOnly/noanalysis, read qualified
protected originals through owned decoders, write bounded original analysis scripts,
local receipts, documentation, and disposable text patch-verification trees.
Independent read-only review follows WORKFLOW/protocol. No game/process attachment,
native invocation, save creation/modification, deployment, configuration or analysis
database changes, downloads, external disclosure, staging, commits or pushes.

Inputs: fresh version/hash baseline, pinned E2 definition inventory with physical
rereads, original installed definitions, existing E1-E3/P1 contracts, four explicit
historical originals. Outputs: authored storage reference and metadata tables,
owned research scripts, ignored local source/save/native/test/check receipts,
complete/task-only text diffs and manifests. Raw/proprietary/private data excluded.

Risks are interpretation/framing errors, accidental source mutation, stale pins,
unbounded decoding and local disk consumption. Preserve strict existing decoder
qualification/bounds and caller-available 40,000,000,000 bytes on C: and D:.
Stop affected work on a failed guard, pin mismatch, source corruption or unauthorized
operation. No evidence-volume/time cutoff is invented. Ghidra exports can allocate
and write tool caches/logs but must not alter the imported program/database.
The existing owned session's stop marker ends further export requests; its finite
offline session bound is not a live experiment rule.

Cleanup: source saves untouched, decoded scratch removed by context exit, read-only
native session stopped normally, database and HEAD/index bytes compared. Retain
all earlier receipts, unsuccessful address guesses, cap flags and corrections.
No source restoration, file deletion or Git integration follows completion.

Ordinary scoped conclusions may be STRONG without an observer or a complete
game-wide inventory decoder. A real unsupported representation remains a coverage
gap; an unexamined mandatory route is not negative closure. Further live actions
require a separate falsifiable brief. Research confidence, assignment acceptance,
current runtime realization and publication eligibility remain separate outcomes.
