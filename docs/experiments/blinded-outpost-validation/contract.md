  engineering, isolation and editorial dispositions are separate. Closure deltas
  require review. Reviewer acceptance does not authorize Stage B or integration.

## Route selection before implementation

The existing Python audit hook is useful telemetry but explicitly lacks operating-
system isolation. Prefer an OS-enforced disposable restricted process with a
provisioned runtime and no network capability. An operator-provisioned separate
offline account/VM is the fallback if this host cannot create a suitable boundary;
same-agent role switching is insufficient. A file bridge is smaller and easier
to audit than a new observer framework. Existing native contracts are reused
offline; no new live collector is built. Missing effective-centre and acquisition
evidence remains an explicit Stage B prerequisite.
