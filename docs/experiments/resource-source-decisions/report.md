## Implementation choice and limits

The smallest route extends existing all-stop hardware-breakpoint, SRO1 durable
receipt and external ACK machinery. Reusing D5B unchanged would retain coverage
gaps. New hooks/injection or a broader lifecycle tracer would add intervention
and qualification work beyond the selected decision contract. Four fixed slots
retain visited/map plus conversion/mask operands; construction completion and
lifecycle fences are explicitly missing rather than inferred from silence.
These are reviewed AC4 blockers, not an abandonment of source-decision research.

The [native table](native.md) gives exact stack arithmetic, branches, locks,
rejection conditions and reset/destructor addresses. Repeated pointers, source
keys, byte hashes, thread frames and timestamps cannot establish generation
ancestry. Native query/mask-only stops are D until an actual branch is observed;
qualified branch stops remain C with named missing fields. Synthetic A/B use
explicit fixture-only lifetime witnesses and cannot be transferred to retail.

Bethesda supplies the existing native evidence; the maintainer supplies Save52,
prior captures and owned project methods. [Per-use provenance](sources.csv)
credits D5B/D4 debugger utilities, C1 SRO1 transport, D4 independent decode,
D5C/D5D lifecycle/demand findings and D5A frozen alternatives under SOR-P-0002.
No new outside implementation, licence decision, external contact or disclosure.
B6/publication stays on hold. No tracker integration or Feynman VIII-b work.
