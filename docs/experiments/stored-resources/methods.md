## Preserved failures and corrected interpretations

Initial broad source reads exceeded console output limits; later targeted reads
recovered decisive policies and relevant records. Early missing-export reads were
made before the healthy worker flushed them; they are not absent-provider evidence.
Exact-symbol reconnaissance scans were slow but completed, without a time cutoff.

Some guessed interior/non-entry locators return NO_FUNCTION_AT in n018/n023/n024;
they are failed locators, not semantic exclusions. A missing-function selector in
the console slicer raised StopIteration; later queries selected actual entries.
Two duplicated/mistyped CPython command paths failed before execution. No failed
acquisition is a scientific negative. Native exports remain exclusive and intact.

The first case-register pass wrote corpus/cases then failed because the existing
definition index omits beacon ACTI 2c60e9. Recovery physically reread its known
record offset, asserted tag/FormID and all fields, and reproduced the existing
CSV bytes exactly before completing case-definitions/source-controls. No input
was repaired or rewritten. Two preliminary nonresource selectors failed on absent
index fields and unrelated extra-entry shapes; the durable corrected selector
restricts Extra4C, handles missing definitions and completes the stated census.

The first icon-tree query expected children directly in SymbolClass 53 and found
none. Actual imported class placement is in row sprite 118; import/instance
metadata and PlanetInfoCard SymbolClass 18 complete the join. No missing-icon
claim used the failed parent assumption. ABC 02 additionally retains exception
tables; ABC 487 has no catch, limiting unsupported-name fallback claims.

The early chat update called the paired 375-unit cargo item Helium-3; the exact
MISC0057df join corrects it to Caesium. The correction was explicit and cases.csv
uses the actual identity. An early draft misdescribed the lifecycle forwarding
slot as periodic/no-op; the actual table forwards to exit. The final report
claims only entry collection and bounded absence of an inventory-refresh path,
leaving external lifecycle re-entry unqualified.

The first review exporter stopped at git diff --check because five new index
additions ended with an extra blank line. The check ran before patch creation;
sd3-eof-fix.py repaired only authored additions, and review01 then reconstructed
both patches exactly. Context-mismatched apply_patch attempts failed atomically;
their corrected applications did not change protected evidence.

Independent review01 returned REWORK for the omitted default-entry zero-to-one
preparation in n014. The revised aggregation explanation separates prepared
constructor input from initialized stack sums and actual displayed quantities.
The focused regression checks the actual CMP/CMOVC instruction window, successful
loop invariant and call-argument storage for zero, positive and high-bit values;
it also checks the separate initialized-zero visitor path. No generic constructor
or game/ActionScript is executed. The original review/verification receipts remain.
