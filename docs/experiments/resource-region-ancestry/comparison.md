## Stage1: consumed regions first

1. Audit receipt framing/hash/ACK/accounting and exact EXE/source/Workshop joins.
   A source/read failure, missing transfer, wrong stack or lost invocation blocks
   the association; keep any independently useful geometry as diagnostic only.
2. Separate complete native region bytes from context provenance. Decode raw f32
   words without rounding decimal coordinates; retain ordered points, widths,
   bounds, resource and source-slot order. Never compare only an enclosing sphere.
3. Obtain a **witnessed coordinate-frame correspondence** before transforming a
   path into frozen model space. The frozen P3 translation is site XY−(2800,200),
   but it is conditional, not automatically valid in a loaded/rebased cache.
   Use current descriptor/domain/reduction operands and an independently joined
   frame anchor; do not shift regions until they fit. Without this, report
   native geometry present / model-frame correspondence UNKNOWN.
4. Once the frame is qualified, apply ordered binary32 transforms. Match resource,
   point count and ordered XYZW **bitwise first**; list every matching frozen
   source/path, not just the nearest. Report bounds separately. A tolerant
   diagnostic may report max absolute coordinate/width error and ULP distance;
   it cannot establish identity. No tolerance is selected from acceptance.
   Four f32 words per point yield exactly16 bytes; no point reordering, reversal
   or segment collapsing. Duplicate paths remain ambiguous.
5. Compare native decision with the unchanged evaluator only if actual used Qb,
   Qc/Qv XY and Qe XYZ, radii, upper and numeric mode meet its sufficient-input
   rule. Terminal retained Qb is source-backed; Qc/Qv/Qe absent means UNKNOWN
   for multipoint verdict equivalence. Singleton conditional diagnostics stay
   separate from that admission. Negative source coverage cannot be inferred
   from short-circuit terminal observations.
