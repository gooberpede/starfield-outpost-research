## Storage accounting and retained failures

with WinError 50 both normally and in an independently approved read-only query;
PowerShell volume inventory is access denied. real01 stopped before a proposal
or restoration on that unsupported query. The later conservative method credits
only regular, single-link, uncompressed, nonsparse, unencrypted sources larger
than one cluster whose FileStandardInfo allocation is cluster aligned. Other

no MFT or directory recovery is credited. This is a projected file-allocation

under the existing proposed research-system owners, without per-experiment
