## Objective and minimum useful result

At natural Feynman P3 source production, distinguish effective chance admission
from different source/frame/selection and history. Primary read is **XMM3 f32
weight at static VA14079be20 before CALL14079c470**, joined to selected IRES in
RDX, context RCX and actual descriptor R8. Static cont01 bda0..be20 and ui29
c470..c4f7 qualify this boundary. It supplies per-resource weight/order without
waiting for a specific random cell. No return value is mistaken for weight.

Minimum useful output is a qualified source/owner/BIOM/descriptor/IL-weight
receipt and complete read status, even if no historical C1E epoch is reproduced.
It discriminates whether baseline inactive weight is actually used by a new
construction. It cannot retrospectively certify Phase B generation history.
The stronger result also binds a generator cell/key/output and Cu predecessor
population to a later P3 consumption. A weight alone cannot close that claim.

## Implementation proposal and executable observation boundaries

Before approval, implement a separate owned collector revision and synthetic
target under a new brief. Preserve existing C1E binaries/scripts and receipts.
Use read-at-stop copies with durable external SRO1 ACK/readback, exact instruction
guards and measured module base. Debug stops, hardware breakpoints, context
bookkeeping and delayed resumes affect execution and must be disclosed. No game
memory/register value patch, software trap, hook/injection or forced native call
is proposed. Observer-owned debug-register/RF operations need explicit approval.

Four candidate execution sites, to be requalified from actual code before use:

1. `14079be20`: effective ordinary resource/weight/order, selected descriptor and
   source-generation context. Preserve raw XMM3 bits and mask/rarity branch
   operands, actual per-rarity setting words, CTPerBiomeData/component-selected
   RSGD and DNAM. Include Special/Everywhere status explicitly; do not substitute
   this boundary for those branches.
2. `14079c4f7`: generator CALL boundary. Capture register arguments RCX/RDX/R8/R9,
   stack+20/+28/+30 and pointees, X/Y at the call, actual source/clip/origin,
   resource, DNAM, owner and full earlier different-resource regions. Native
   packed key/CRC is acquired at its actual internal producer only after a
   separate static stack/operand qualification, or recorded as DERIVED rather
   than observed. No invented packed key from source+68.
3. `14079ff1d`: after synchronous producer returns, before visited append. Bind
   the source and inserted wrapper, completion/early-exit status, complete
   source/resource geometry and generation invocation token.
4. `1421e1772`: true consumer ACCEPT, using existing qualified C1E saved-frame
   P3/slot/collection/region/namespace binding. Capture native IL and Cu as
   controls. A separate transfer phase may use the existing C1E four-site map;
   switching phases introduces a disclosed epoch gap and cannot certify history.

These four sites do not cover every reset/destructor/alias writer. Therefore a
continuous generation→consumer epoch claim remains **UNKNOWN** unless a separately
qualified lifetime mechanism excludes replacement/ABA through that whole interval.
Do not infer one from repeated pointers, same geometry hashes or elapsed time.
Do not silently expand beyond four hardware sites or add software instrumentation.
The narrow first acquisition can succeed on generation operands without an epoch
claim. A failed native read is LOSS/INCOMPLETE, never zero/absence or baseline.

## Success, stop and recovery

Scientific minimum: qualified actual effective generation operands with source
identity/type and explicit epoch limitations. Stronger success: complete native
IL+Cu generation inputs/outputs and independently qualified consumer join. No
claim of causation until all three exact controls and alternative explanations
are assessed. New evidence cannot identify the historical Phase B epoch by fiat.

Stop on operator STOP, complete declared acquisition, identity/guard mismatch,
failed disk guard/query, corruption outside the declared evidence boundary,
worker failure, evidence/ACK integrity failure or unqualified lifetime/budget.
Flush/preserve complete evidence; failed pre-evidence acquisition is not success.
Post-capture target exit may be crash-tolerant **only if explicitly approved**;
record debugger-induced failure versus controlled exit versus target survival.

no overwrite of protected originals, seal/stream-verify a lossless local archive,
retain raw originals, report any added/missing/changed files and seek recovery
decision on unexpected corruption. Remove only this newly approved instrumentation
