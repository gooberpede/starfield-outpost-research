## Scientific result

The [ancestry ledger](native.md) traces the ordinary CALL backward through the sorted pointer array, assigned-root lookup and owner-range component map construction. The component bytes copied during Tungsten call 88 contain BIOM numeric word `0x0028acd1`, root `0x000057d5` and zero supplemental slots. The typed entry BIOM prefix and full owner-range traversal were not captured. Matching these numeric fields to D3 does not establish every loaded definition or historical component identity.

The first supported offline divergence is precise: `corpus_d3.py` projects `family.emitted_form_ids`, whereas native `0x14079bc1b..0x14079bd17` appends the assigned-root map's resource IDs before rarity sorting. Map construction visits the owner's component range and exchanges arrays under each nonzero root. It is not simply a merge of every BIOM family, nor a resource-density fallback. The [hypothesis ledger](hypotheses.md) preserves competing mechanisms and falsifiers.

Diagnostic replay v1 supplies the actual four calls from each corresponding source invocation: two zero-weight Water operands, Tungsten with effective binary32 weight approximately 0.2, then Chlorine with weight 1. It uses each call's selected DNAM rarity block, with unchanged D3 source enumeration, source origin, packed seed calculation, random draws and geometry arithmetic. No observed geometry is used to select or fit an input. Geometry comparison occurs after the result is written. This is explicitly observation-informed reconstruction, not blind prediction.

Water has zero chance threshold in these finite-vein calls and supplies no generated points; its terrestrial/atmospheric availability remains outside this discrepancy.

There is no independently established whole-corpus correction: the runtime map's ordered component inputs and displaced arrays are missing. Accordingly D2/D3 code, corpora and predictions remain frozen, and no saved-positive classification is silently promoted. All 17 active requests in each frozen D2/D3 roster are rerun unchanged, while the two disabled cases remain in the original 19-case inventory. Seven Feynman/Carinae native controls are rerun in both D1 representations. The replay explains the three sampled geometries conditionally; it does not enumerate visible deposits or reconstruct the historical cache epoch.
