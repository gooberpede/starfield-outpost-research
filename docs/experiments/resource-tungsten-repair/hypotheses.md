| Mechanism | Test and falsifier | Result and limit |
|---|---|---|

Falsified if CALL list is exclusively the selected component's own emitted family. | Supported: root-keyed owner-range map supplies extras, while call 88's selected component has zero supplemental slots and D3 omits Tungsten. Exact map node remains missing. |
| Alternate component/family traversal or merging | Inspect descriptor search separately from map production. A sole descriptor-alternate mechanism predicts admission only after an alternate descriptor is chosen. | Map production precedes descriptor search and may draw from other component records. Descriptor identity is still not uniquely established by the matching hash. Root-keyed array exchange is not a blanket union; loaded visitation order is required before correcting the builder. |
| Per-resource occurrence/density cap, area budget or fallback | Inspect owner-map append/exchange and ordinary generator/cell paths for counts controlling resource substitution. A resource-set omission caused by spatial exhaustion would require a backward admission/fallback edge. | No spatial quota-driven resource substitution appears in the inspected map/ordinary CALL/cell/competition paths. Rarity weights, descriptor attempt counts, finite source bounds and upstream selection capacities are different controls. This bounded negative does not exclude every engine path or historical setting. |
