# Editorial and delivery compliance

The final changed prose inventory includes every new document in this experiment, all navigation/source/permission/credit additions, explanatory comments/docstrings in the changed controller/fixture and new Python methods, and the supplied brief as separately identified input. Existing historical text is not bulk-corrected. All authored additions use UTF-8 without BOM and LF endings.

After science/code/tests, `research/editorial/screen.py --changed` ran with the installed CPython executable and returned zero diagnostics. Its complete diagnostic/inventory output is retained in each local review package. The standard CLI does not select C++ files; the package helper additionally applies the same line rules to every line comment in both changed C++ files. This is a disclosed coverage extension, not a claim that the CLI supports C++. Manual review read every changed authored paragraph, table, label, comment and docstring, including the source/permission/credit/navigation additions. CSV labels and repeated use/classification text were read; opaque identities receive byte/hash verification. Local links and notation are checked separately by the package exporter.

Manual corrections changed an overbroad statement about terminating-thread context availability to a conditional statement and reconciled final build/receipt labels. The initial replay import error was corrected and successfully rerun before scientific results. No automatic prose rewriting or editorial suppression was used. Static VAs/FormIDs/byte offsets use hexadecimal, while counts, cells, thread IDs and measured quantities use decimal. Code identifiers and literal prior errors retain their spelling.

Manual review preserves the important qualifications: observed component numeric fields do not become typed BIOM/namespace proof; exact conditional geometry does not become a historical producer join; old post-ACK rearm reproduction does not become reproduction of `win32=31`; intentional controller failures do not become clean shutdowns. Three controls do not become an exhaustive visible-deposit census. The unbuilt prospective extension remains unapproved.

The independent reviewer must read the exact final changed text and primary evidence under [the reviewer procedure](../../reviewers/research-completion-reviewer.md). Its [disposition](review.md) binds file hashes. Export complete/task-only diffs only after that review snapshot, and re-review any substantive later delta. Local delivery manifests record whitespace/link checks, exact path/content coverage, forward/reverse application, exclusions and preserved HEAD/index. Screen success alone is not independent or semantic editorial acceptance.
