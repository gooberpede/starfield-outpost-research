## Reuse and finite acquisition scope

Reuse the C1G four hardware execution sites: preferred static VAs
`0x14079b520`, `0x14079be20`, `0x14079a59e`, `0x14079ff1d`; RVAs subtract
`0x140000000`, runtime VAs add the freshly measured module base. These stops
pause/step the target and alter owned debug-register/RF state; they may change
timing or crash the process. They are disclosed instrumentation.

The existing C1G controller is a method reference, not a ready D3 binary. Its
old P3 completion selector must be replaced by reviewed profile/source criteria.
No old binary is admitted merely because its prior tests passed. Before live
approval, retain final source/binary hashes, exact instruction preimages,
call-destination checks and synthetic profile tests for all admitted sites.
Qualification must include wrong owner/frame, partial reads, nested calls,
thread joins, no-hit and durable evidence before process failure.

At provider entry, let E be RSP: RCX is the actual source, RDX origin pointer,
R8 geographic construction-query pointer, R9D manager owner; `[E+0x28]` is
BIOM and `[E+0x30]` output map. Copy source `0x70` bytes, origin 8,
geographic query 16, BIOM prefix and measured manager/frame identity. Working
frame F is E minus `0x2d8`. At ordinary CALL copy component result
`F+0xe0` length `0x68`, selected RSGD at `F+0x80`, DNAM at `F+0x68`,
ordered list pointer/count `F+0x50/+0x40`, current resource and low mask
`F+0x30`. Bound every pointer read against its declared length and verified
allocation/readability; partial/truncated data is not a qualified result.

Extend the entry/call receipt to retain the query-derived raw mask byte and
the selected descriptor's complete 560-byte serialized-equivalent payload,
with an explicit native-memory layout conversion. Preserve raw native prefix
separately; native descriptor stride `0x238` differs from serialized length.

## Admission, protection, durability and stop policy

Before approval/execution, use shared phase-aware session preflight: verify the
target absent, actual game/Steam/sync paths and configuration/tool identities;
confirm Steam Cloud disabled; independently hash designated research saves,
manual/quicksaves, original archives and recoverable backups outside write/sync
paths. Fail closed on unclassified saves. Active reliably classified autosave/
exitsave rotation is diagnostic only. Do not restore it to satisfy equality.
Rehearse recovery only on a disposable copy; never overwrite a protected save
or the sole recoverable backup. Require 40,000,000,000 caller-available bytes on
both C: and D:, at admission and during the session.

After approval, launch through Steam, attach at the main menu before the single
controlled load, perform only the selected profile's natural action sequence,
and dispose of the observer through its reviewed terminal path. No game byte,
register other than declared debugger-owned state, configuration, plugin,
analysis database, source selection, cache, or save modification is proposed.
No construction/deletion, intentional manual save, console call, arbitrary
memory invocation, reload loop or automatic retry is allowed.

Persist sequence-framed evidence, SHA-256 and durable ACK before resuming.
On complete useful evidence, stop collection and use the separately approved
detach/exit/disposal policy. On completion of the finite natural action sequence
with no generation, record NO_HIT and request an operator decision; do not force
a miss. On failed identity/instruction guard, corrupt framing, actual worker
failure, low disk or explicit STOP, halt capture and follow the reviewed terminal
policy. Slow operator response or a missed routine poll is a deviation, not
an automatic failure or termination trigger. There is no arbitrary elapsed-time,
event-count or evidence-volume cutoff.

The future approval must explicitly choose clean detach versus crash-tolerant
acknowledged process disposal. This card does not itself authorize termination.
Complete durable evidence survives a later process failure scientifically;
pre-evidence failure is not success. Unexpected corruption outside the declared
boundary stops the run and preserves state for a recovery decision. Do not
silently pass/suppress exceptions or restore originals.

After the approved process exit, perform full offline postflight against the
prelaunch strict hashes, record transient diagnostics separately, preserve all
failed receipts and seal/stream-verify a lossless local archive. Report scientific
result, evidence completeness and process survival separately. No upload,
publication, commit or further live run follows automatically.
