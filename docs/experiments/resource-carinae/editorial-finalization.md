# C2A editorial finalization

The governing [standard](../../EDITORIAL_STANDARD.md) applies to every changed
prose file, table, caption, index entry, explanatory comment and docstring.
The supplied brief is retained verbatim and identified separately in delivery.
The original source/output hashes, status, screen inventory/diagnostics and
independent exact-snapshot disposition remain in local C2A receipts and
[review](review.md).

Sequence: finish instrument/tests and scientific scope; run
`research/editorial/screen.py --changed` and `research/editorial/test_screen.py`;
manually read the complete changed authored prose; correct defects; obtain
independent review of the exact changed-file snapshot; verify/export both patches
and manifests against that snapshot. No substantive later edit is accepted
without independent delta review.

Manual review covers the four navigation/register edits, all C2A Markdown,
numeric-summary labels and source CSV roles, and all new source comments/docstrings.
It checks readable spacing, UTF-8/LF, local links/Markdown, pointer/token/handle/
FormID distinctions, RVAs and object/stack offsets, conditional versus observed
query results, accepted edge versus callback return, pre-install transfer versus
cache installation, and source-pointer identity versus generation epoch.

No historical evidence text or existing typo was bulk-normalized. Opaque raw
bytes, hashes, exact machine identifiers and the supplied brief retain identity;
their exclusion from prose rewriting does not clear scientific interpretation.
The screen is a bounded suspect detector, not proof of readable or correct prose.
Final diagnostics, reasoned exceptions, manual coverage and independent reviewer
decision are recorded in the finalization/review receipts. Material defects return
this same task as REWORK.
