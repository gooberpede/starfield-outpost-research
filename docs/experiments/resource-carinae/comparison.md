# Prospective nonfitting comparison contract

[C2A comparator](../../../research/resource-carinae/compare.py),
[identity and native contract](contract.md), [run card](run-card.md),
[immutable C1H baseline](../resource-installed-settings/comparison.md).
No Phase B or retail Phase C interpretation was performed in Phase A.

The exact comparison input is the local C1H `geometry02.json`, hash-bound by
the immutable C1H source ledger. It contains complete installed-settings source
populations, rather than selected points. The comparator verifies that pin and
each closed sample's SRO1/ACK framing before comparison. Synthetic files are
marked synthetic. Retail files require the separately supplied Phase C receipt;
the file records authority and cannot create it.

For every visited decision, report these independent axes:

| Axis | Contract |
|---|---|
| Reference/consumer ancestry | Exact typed Carinae BC Workshop join, actual runtime reference, exterior-cell context, same thread lifetime/updater/frame/temp-set and exact later transfer resource pointer. Unbound/partial records cannot qualify. |
| Producer source/frame identity | UNKNOWN without an independent source-context/producer witness. Slot ordinal/key/wrapper are observations of consumer scope, not a BIOM, packed geographic source key or generation epoch. Even an exact geometry match does not prove identity. |
| Geometry | Compare all four little-endian binary32 bound words and every ordered XYZW point word at the same IRES identity. No tolerance, rounding, point sorting, translation search, scaling, fitting or output-only digest inference. Return all exact source/cell candidates; an empty match list is a scoped geometry mismatch, not absence. |
| Region classification | Retain observed ACCEPT/REJECT. Separately replay the existing area evaluator with captured retained Qb/radius/upper, labeling that result conditional on retained-word/per-use stability. Do not replace captured Z/upper with planar defaults. Complete per-use multipoint replay is not newly qualified. |
| Transfer/cache/catalogue | Exact same-invocation pointer membership is pre-install evidence only. Completed cache install and final catalogue result remain NOT OBSERVED. |
| Coverage | Visited terminals only. Deduplication or short circuit can hide other regions. Missing events, failed reads and skipped sources cannot establish a census or native absence. |

The six comparator tests exercise exact positive bits, one-bit point/bound
differences, point order, wrong IRES, identity/corruption refusal, absent or
misbound transfer and no-hit cases. Synthetic exact-match candidates are
constructed explicitly from fixture bytes; they test comparison mechanics,
not agreement with actual Carinae predictions. The authorized synthetic CLI
also compares a closed fixture against the immutable full baseline, expecting
no exact match. No shared generator is changed.

| Future observation | Scoped interpretation and next dependency |
|---|---|
| Accepted Iron region with no exact baseline match | Positive native consumer evidence. First compare selected source/frame, BIOM/RSGD, mask/settings and generation inputs. Do not fit an offset or change a seed to force equality. |
| Exact native Iron geometry but modeled area misses | Investigate actual retained/per-use query, spatial predicate and association. Geometry equality alone does not clear consumer assumptions. |
| Context differs | Localize the earliest independently demonstrated source-selection discrepancy before adopting any correction. A single-biome beacon does not select the effective source BIOM automatically. |
| No generation event but valid accepted cached region | Preserve consumer geometry/transfer evidence; historical inputs and generation epoch stay UNKNOWN. |
| No qualifying Iron or no Workshop binding | No-hit/identity failure, not Iron absence. Preserve controls and loss diagnostics and use only the bounded contingency in the card. |

The Feynman hard regression gate is unchanged C1H replay: all 156 baseline
paths regenerate, all four accepted native paths match installed geometry,
all three chance comparisons agree, Copper survives and no extra IL path is
introduced at (11, 1). Carinae's 895 paths remain identical. Historical freezes,
settings provenance and prior live receipts are protected before and after the
assignment. Scientific disagreement remains open independently of engineering
acceptance and publication eligibility.
