| Script | Reads / writes / prerequisites / target effect |
|---|---|
| `build.py` | Reads original C2A/C1D source and installed MSVC/SDK; writes a fresh ignored build and manifest. No target execution. Requires both-drive free-space guard. |
| `qualify.py` | Reads a hash-bound build; executes only the separately compiled original synthetic fixture/controller. Writes fresh ignored raw synthetic captures, ACKs, event/config/results and qualification JSON. Debugger intervention/termination is confined to disposable fixtures. |
| `test_compare.py` | Reads closed synthetic qualification output, writes nothing; six mechanical comparator tests. No process or source-data mutation. |
| `compare.py` | Reads closed SRO1/ACK/events and pinned C1H full geometry; writes a fresh ignored derivative. Synthetic Phase A use only now; future retail use requires explicit Phase C approval. No target operations or fitting. |
| `preflight.py` | Offline EXE/definition/config/save/backup/source/build/qualification reads, static guard verification and one new scratch Save52 restore copy. Writes a new ignored receipt; active saves and protected backups are read-only. |
| `postflight.py` | After-exit full hash inventory/difference audit; writes one fresh ignored receipt before assertions. No restoration, cleanup or process intervention. |
| `collect.py` | Future approval-gated PID attachment through the compiled controller; no launch. Writes consumed/config/events/SRO1/ACK/accounting files to new ignored paths.
