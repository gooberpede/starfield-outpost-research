## Owned analysis and independent native evidence

[cases.py](../../../research/resource-query-variability/cases.py) version 1 adapts
owned D5H `domains.py`, `roundtrip.py`, `native_sine.py`, `occupancy.py` and
`witness.py` from the starting HEAD under SOR-P-0002. It uses installed CPython
3.14 and stdlib, reads an explicit lease and independently pinned payload hashes,
checks canonical corpus framing, and reads three bounded BA2 members through
the unchanged owned BA2 method. The lease manifest hash is also checked.
Archive/member authentication occurs in the explicit preceding restore, not
merely by trusting a caller-supplied lease digest.

For each source, whole contributing SFPT tile anchors are enumerated with the
native installation transpose. Candidate source bounds include the maximum
22-cell nominal dimension in the pinned corpus. Each contributor's actual
dimensions, raw coordinate, flag and setter slot are checked. Every insertion
permutation is replayed at each query. Unsupported mixed cell kinds, X-edge
or corner contributors abort; the selected pairs require only fill/Y-edge cells.
The method does not pretend to be a general source-grid emulator.

For both original roots it evaluates the actual four density-neighbor coordinates
through both inherited instruction-derived SIMD paths, then samples the installed
low-nibble raster. It independently derives ordinary vectors from corpus resource
rarities/settings and checks them against D5H. Only offline host CRT `cos/atan2`
execute, on owned numbers; no game instruction or DLL entry point executes.
The pinned host is `C:/Windows/System32/ucrtbase.dll`, SHA-256
`3c60056371f82e4744185b6f2fa0c69042b1e78804685944132974dd13f3b6d9`,
with query-only control word `0x8001f` and RN bits. Historical host equality and
large-angle fallback are not assumed. Constants and source/helper hashes are
bound in `cases02.json`.

The numerical result is explicitly not an admission oracle. [QS1](proofs.md)
separately joins actual ingress, placement, initializer, worker consumer and
provider success. Native lineage is inherited from D5H's reviewed primary
exports; no new Ghidra export or analysis change was needed. Fresh current-PE
reads revalidate all 278 previously pinned function range sets and ten module

including the five legacy exports. Byte identity does not prove semantic extent
