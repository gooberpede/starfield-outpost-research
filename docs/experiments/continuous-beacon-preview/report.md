## What the evidence channels mean

Native evaluation position is an actual argument snapshot taken at the hook
boundary, not player XYZ or a later reference sample. Indexed domain type/FormID,
frame index, held preview reference and base are retained. Reference/cell/world
walks are separately sampled; pointer/header equality is not atomic frame proof.
Three raw output populations retain duplicates/nulls/unknowns. AL indicates native
refresh/update, not set difference. Decoder population signatures are named as
such, because unfiltered biome definitions are not the displayed union.

UI invocation identity is its own scope. Exact first/second consumer ranges,
actually selected special appends and final row ordinals support an independent
input-versus-row reconciliation. Constructor input identity is associated only
after the final container count/ordinal census. Growth relocation is handled by
ordinal rather than old row address. No FormID is invented inside display fields.
Raw row bytes remain available. Agreement is not observed rendering.

Shared-vector snapshots and overlap/epoch bits are diagnostic. A native evaluation
can refresh to the same set; a UI delivery may consume a later set or skip during
unchanged evaluations. The decoder retains every evaluation and exposes all
matching non-overlapping first/second-population candidates. It never selects the
latest one as unique causal ancestry, and never upgrades candidate equality into
world/position equivalence. Third-source snapshots are explicitly non-atomic;
actual selected append evidence is used for the native row reconciliation.
