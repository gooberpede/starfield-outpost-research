## Prediction independence and portable coverage

The [D1 algorithm](../resource-standalone/algorithm.md), schema, numerical code
and generator are unchanged. Preparation recomputes whole-planet selection
before projecting every geographic halo. It neither selects resources from
outpost names nor takes extractor labels, runtime source anchors or expected
geometry as prediction inputs. The model retains D1's empty-atmosphere occupancy
assumption and main-definition scope.

The local corpus extends the original 16,792-byte normalized corpus to 735,952
bytes, an incremental 719,160 bytes. It covers 16 bodies and 204 requested/margin
tile projections, while retaining D1 control tiles. No new schema field or
generation operand was introduced. Additional fields are instances of existing
PNDT system/index, SFTR/SFPT/SFBK routes, source BIOM/mask and selected family/
RSGD block fields. Map members are uniquely matched from installed PNDT EDIDs
to archive names; the pinned archive, member digests, lineage and unsupported
paths are in `build-v1/manifest.json`. This is a field projection, not a full
planet raster or performance optimization.

Every isolated inference process reads only its explicit request, completed
corpus, copied five-module code and interpreter runtime. Each of the 17 audit
logs records eight denied forbidden-read probes and zero forbidden inference
accesses. This is a Python audit boundary, not an OS sandbox. Raw source bytes
and the complete string pool necessarily pass through preparation; resource-coded
navigation names are loaded there. The claim is independence of predictor
inputs and deferred comparator joining, not human ignorance of every label.

The input/corpus freeze precedes all inference. Predictions closed at
`2026-10-23T23:16:06.777525+00:00` (24 October in Sydney); first comparator answer
access began at `23:17:01.458433+00:00`. The prediction-freeze SHA-256 is
`e7aaeef2f7486b5f77be5538ba9405009baa93fd0fa75e2152e05f63e7d87f67`.
It binds the label-free case/control roster, exact requests, corpus and output
bytes. The full navigation inventory did not receive a separate precomparison
hash in that original manifest. The corrected comparator asserts its eligible
case/control/request projection exactly equals the frozen roster before joining
answers; final source and inventory hashes are retained separately. No first-pass
prediction was replaced or adjusted after answer access.

Coordinates use the existing site-centre projection and saved frame `0x2b`.
The recovered angular pair must project uniquely within 0.001 fine cells of a
grid centre, agree with the descriptor chart and remain interior. The query is
the compensated saved centre translated by 100 native units per site-to-descriptor
fine-cell difference, rounded to binary32. Every case uses a fixed 150-unit disk
and upper scalar centre Z + 100, declared before resource comparison. This is a
common research footprint, not a reconstruction of each saved hardware footprint
or an unobserved loaded manager/rebase. Marginal native rounding and historical
frame/epoch equivalence remain unvalidated.

## Counterexample and coverage-class findings

**First priority: Archimedes III Tungsten.** Case `D2-81a75b` has a positively
qualified saved Tungsten extractor, token `81a814`, IRES `0x000057c4`.
The complete modeled halo has four sources, raw SFPT flags `0x08`, uniform mask
zero and source BIOM `0x0028acd1`. Its selected RSGD `0x0037c66c` emits only
Chlorine `0x000057d5`. Tungsten is therefore absent before path generation.
The same planetary calculation emits Lead/Tungsten in a different biome,
`0x002636ba`, through RSGD `0x00007edd`; it was not globally discarded by the
resource-identity reader.

The bounded diagnostics inspect typed source routes, all contributing source
biomes, nearby tile definitions, masks, coordinate translation, complete source
generation and exact extractor ownership/resource identity. No unresolved halo
or nonuniform mask explains this particular mismatch. Historical cache state,
effective native biome/component selection, overrides and prior vein changes
remain possible explanations. No cache-generation epoch is recorded by the
surviving extractor. This is a counterexample to correspondence with the current
conditional model, not proof of a numerical generator defect. The next
discriminator is the effective native source BIOM and component resource list
at this qualified site; see the [unexecuted prospective card](prospective-run-card.md).

**Second priority: mixed source masks.** Four held-out cases encounter
`UNKNOWN_NONUNIFORM_SOURCE_MASK`: Feynman VI-b, VII-b, VIII-b, the second
Feynman V site. The precise case inventory is
[cases.csv](cases.csv). The second Feynman V case is blocked by four mixed-mask
sources, not by deletion. Feynman VIII-b retains Copper/Antimony positives while
Gold stays unknown. A single tile mask cannot substitute for a per-cell sampler.

**Third priority: unrepresented component branches.** Three held-out sites have
selected Special Helium-3 `0x000057f5` alongside ordinary families; D1 cannot
establish their generation/competition semantics. Feynman I and III encounter
source biomes without an ordinary family in the projected selection. Seven
unsupported body/biome projections are distinguished in `diagnostics-v3.json`:
three selected-Special, four no-family. Nearby unused tiles also contribute to
the corpus's 70 unsupported tile rows; that number is not a count of failed
outposts or failed predictor sources. No-family is an unsupported preparation
branch, not proven terrain absence.

Water IRES `0x000083ec` is separately admitted. Both encountered Water extractor
bases contain HarvesterAtmosphere AVIF `0x000083ff`, value 1.0. The established
[native property branch](../resource-availability/report.md) tests property
presence and selects a separate collection; it does not use value positivity
as a substitute for presence. The four Water pairs are excluded even where
finite-vein geometry is unsupported. No absent Water or exhaustive final UI
catalogue claim follows. No site exception, seed fit or geometry shift was made.
