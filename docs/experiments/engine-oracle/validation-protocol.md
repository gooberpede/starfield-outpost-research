## Comparisons fixed before collection

1. Validate executable/plugin/module hashes, completeness, source bytes and
   associations. A passing integrity check does not establish semantics.
2. For stored native output, preserve all before/after bytes, pointer provenance,
   center/radius, flags and active-context diagnostic. Classify freshness and
   frame independently. Native radius150 is the existing ordinary definition
   expectation, conditional on that active ordinary workshop; it is not fitted
   to the capture and not the primary durable-position result.
3. With same-frame/identity/freshness established, require **exact 12-byte center
   equality**, body equality and controlled invariance/distinction. No numerical
   tolerance is permitted for this comparison. Capture outside build mode and
   switch controls are negative freshness controls, not extra passing samples.
4. For callback output require native resolution256 and block12, exact body,
   base hierarchy, input reference and translation. Compute the separately
   predicted translated center by native-order float32 additions, then float32
   scale/floor and signed seam offset from the *captured native input base*.
   Compare translated-center bits, floor integers and output cell exactly.
   This is a conditional native-input replay, **separate from saved-input end-to-end
   validation**. It cannot establish save→current-base/translation correctness.
   Preserve opaque pattern/block handles without inventing expectations.
5. End-to-end cell equivalence under rebase needs observed translation and base
   reconciliation to the saved descriptor/site branch. Record both representations
   and show their transformation; a different frame is UNASSESSED until resolved.
   Do not accept matching final cell with wrong native intermediates, or introduce
   epsilon/posthoc per-case offsets. A failed exact comparison is retained as a
   counterexample; freeze any revised model and new predictions as a new round.

## Adverse cases and holdouts

Offline controls cover no-action repeat, both-axis seam, negative-X site-frame,
signed-zero copy versus vector-wide addition, identity mismatch, missing frame
inputs and unsupported schema/disabled/nonfinite/subnormal domains. Synthetic
debugger sentinel results are SYNTHETIC, never native Starfield evidence. Zero-hit
and unreadable fields remain NOT_OBSERVED/PARTIAL. Repeated equal snapshots are
not independent discoveries. Old nine captures contain inputs, not this oracle.

After first reviewed live round, select a previously unused, provenance-backed
ordinary outpost with supported frame/body and no unresolved join. Freeze its
save extraction and predictions **before** any new output is inspected. Prefer
one origin-relative and one site-relative/negative-axis case if available;
Save52 deployment is not required for the first session. A fresh controlled
relocation/reload and quantization-boundary sample require separate scope and
protected original saves. Report confidence, coverage and claimed completeness
independently: center validation does not validate current grid, arbitrary-angle
quantization, all builds, all outpost types or continuous geography.
