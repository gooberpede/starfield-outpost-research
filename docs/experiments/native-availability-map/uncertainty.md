## Bounded relevant route disposition

The investigation checks the outer caller/descriptor derivation, area updater's
actual arguments and refresh branches, complete loaded table traversal, resource
resolution/type filtering, all recovered spatial predicate branches, definition
contributions, provider cache hit/miss and concrete component/descriptor/generation
dependencies, lifecycle provider consumers, final synchronous fold and asynchronous
model ownership. Existing definition and saved-component investigations are used
within their preserved scope. No promising unexamined in-scope route is converted
to an impossibility claim: full generation and component-stream reconstruction
could be future research, but do not recover unrecorded same-evaluation live
pointees merely by knowing an owner key or installed definition.

The source-level boundary is concrete: 070 records the 24-byte indexed descriptor,
104-byte query state and final vector/member headers; it does not dereference
ProcGen source/resource maps,48-byte regions,16-byte point sequences or the
actual translation table. The event named `region` is a UI union observation.
Prior archived-extent and saved-component probes are retained at
[the native ledger](../resource-availability/native.md) and
[Milestone B coverage](../resource-availability-milestone-b/validation.md).
Their negative scope is missing complete operands/joins, not global nonpersistence
or fundamental offline impossibility. No additional saved-output proxy could
independently validate the missing region decision.

## Scientific acquisition question, proposal only

For a naturally executed **spatial refresh** in the loaded local area, can the
independently reconstructed callback accept exactly the native IRES pointers
from the complete loaded region census at that evaluation's translation/cache
epoch? A minimal decisive observation contains indexed position/domain, actual
translation table entry (or qualified out-of-range index), radius/upper bits,
prior cached state and guard result, every occupied source/resource entry,
resolved IRES identity/type, region counts/centers/radii and ordered XYZ/width
points, plus accepted spatial output. Source-generation completion and relevant
mutations during the census must be qualified. A separately linked actual UI
consumer captures atmosphere/biome populations, water selector and resulting rows.

Outcomes distinguish (1) exact spatial and final-fold agreement, (2) arithmetic
or frame mismatch, (3) correct current geometry with deliberately retained old
cache result, (4) incomplete/pending generation, and (5) correct spatial result
but different asynchronous consumer epoch. A set transition alone cannot select
among these. An established Workshop observation with its builder output would
separately test the inferred context convergence. This question authorizes no
observer implementation, hook, launch, process access or new save.
