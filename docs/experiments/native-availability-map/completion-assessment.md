arbitrary timing. The array belongs to mutable operation state; IRES pointee
lifetime is separate, and no all-writer lock/lease is established. The old
capture proves successful owned evidence reads in observed events, not safety
for arbitrary future readers. This constrains use of the reference without
obscuring where calculated identities are accessible during normal execution.

Established runtime descriptor/output association and preview equality remain
NOT TESTED. Static reference→descriptor→updater→shared-result mapping suffices
for explaining the normal code relationships; a deployed selected-Workshop
reader would require its own qualification. Matching center values cannot
establish radius, vertical bounds, cache epoch or selected-object equality.

Spatial equivalence and complete upstream generation/readiness remain untested.
All 346 folds validate consumer assembly from its actual inputs, not spatial
membership independently. Cached results may be retained and asynchronous
consumption does not identify a unique producer evaluation. Exceptional planets,
arbitrary remote worlds, save persistence/authority, mod integration and
disappearing deposits are outside this endpoint. None supplies a consequential
missing result-location or function-map blocker to this bounded closure.
