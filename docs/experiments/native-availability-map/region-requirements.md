The upper scalar is the absolute vertex comparison operand in F4AC50. It does
not bound every branch vertically, and must not be treated as symmetric height.
World identity, active world, resident terrain, ready generated maps, and fresh
operation caches are separate conditions. Neither a successful function return,
a nonnull cache pointer, a database task publication nor an empty final list
alone resolves all of them.
