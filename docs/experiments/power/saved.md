## Historical flags, switching and current state

HIST-0036 has saved ExtraFlags `0x840` on all 42 generators and 97 lamps,
78 consumers and 78 levers; 8 consumers and 8 levers carry `0x800`.
HIST-0077 has 50 consumers/levers with `0x840` and 12 of each with `0x800`.
These are actual decoded flag words, not inferred values from capacity arithmetic.
E1's native IsPowered predicate reads mask `0x40`; the saved bit is present in
the former values and absent in the latter. A historical snapshot does not
establish what loading/recalculation will decide, and matching lever/consumer
counts alone does not prove the causal switch state or a shortage.

P1 closes E1's earlier unqualified persistence point within this representation:
the same saver `0x14051ea30`, `static-exhaustion-23.tsv` case `9c` at line
2,082, retains the extra+`18` flag word after mask `0x7ffffffd` and writes
four bytes. The mask retains `0x40`. The corresponding restoration dispatcher
`0x140521620` (RVA `0x00521620`),
`active-outpost-static-30.tsv` case `9c` at line 3,244, creates/selects
ExtraFlags and invokes `0x140545e40`. Thus the historical powered bit is
**PERSISTED**; this does not certify its authority after subsequent load updates.

For example, HIST-0036 Aldumite Drilling Rig `ff01a9f1` base `003a861c`,
REFR [3,076,059, 3,076,515), has saved ExtraFlags `0x800`; lever `ff01a9f5`
base `001b1862`, REFR [3,077,048, 3,078,102), also has `0x800`.
The installed fabricator demand is 12. These facts coexist with the preserved
E3 producer registration/selected resource example. Neither producer registration
nor positive base demand implies that the saved or loaded powered predicate is
true. Switch activation, graph gating and production halt require their own
native contracts; no independent switch Boolean is invented from this pair.

## Checks and limits

Executed checks: six final original pre/post hash comparisons, decoded-stream
integrity checks, full R3 framing closure, explicit reference queue bounds,
positive base joins, graph endpoint resolution and reciprocity counts. Exactly
three HIST-0193 candidate records retain unsupported extras; CB before the wind
gap remains usable. Counted-extra closure means the declared extra loop ended;
it **does not** assert that its endpoint equals the entire record end. Trailing
record payloads remain outside this reader's semantic claim.

Preserved acquisition correction: an intermediate enriched run failed while
sorting an explicit null identity in an endpoint set. The original source had
already been rehashed unchanged; no receipt was written. Filtering null identities
from the endpoint-key set fixed that serialization failure, after which all six
final runs completed. Earlier `instances01..03` and `graph01` remain local history.
Final script hashes are recorded in each final receipt; later formatting edits
or graph-summary options do not retroactively identify an earlier tool version.

This saved evidence establishes actual serialized instances and distinguishes
the two graph representations. It does not determine current loaded totals,
switch causality, deficit allocation order, safe arbitrary invocation or visual
wire art. Those are addressed at their authorized native evidence level in the
rest of P1. No new live experiment is required merely to repeat the saved graph
observation. Original saves remain protected and publication eligibility remains
separate from scientific confidence.
