## Recommendation and remaining gates

Prefer0.1.3 over 0.1.2 for a separately reviewed, action-bounded **two-site center-only
smoke**, conditional on accepting pauses and the observed 7.81-second tail. Grid
remains implemented/independently qualified but off initially. The original 0.1.2
is reproducible fallback evidence, not the preferred lower-latency candidate.
No live authorization is sought by executing a test or implied by this report.

Fully moving durable writes outside the stop would require accepting a volatile
loss window; waiting on an asynchronous writer's durable acknowledgement still
holds the target. A snapshot-wide single flush would weaken completed-field
prefix retention. The implemented per-record append avoids those compromises
without a queue/background-thread lifecycle. An even faster transport would need
a new explicitly reviewed durability contract/architecture rather than silently
relaxing this one. Live call rate, busy-scene pauses, interactions with load order,
common-frame association and actual game trigger reachability remain unknown.

Baseline manifest hashes, original 0.1.2 artifacts, shared observer/helpers,
protected originals/archives, frozen predictions/protocol, game and persistent
Ghidra content are rechecked in the [review](review.md). No integration, scientific
promotion, publication, staging, commit or push follows from these checks.
