2026-10-15. [Report](report.md), [contract](contract.md), [review](review.md).

**Recommend PASS only for the finite synthetic qualification.** It demonstrates
a plausible terminal-continuation and complete-operand ownership route for the
tested classes. It grants no observer implementation or live authority. The
rejected 0.8.0 candidate remains historical and unchanged.

The consequential scientific question remains whether complete native multi-point
region operands produce the same actual acceptance/rejection as the frozen
evaluator. Current game evidence still supplies **zero qualified pairs**, so
spatial native equivalence remains **NOT TESTED**. Fixed-quad arithmetic and
synthetic replay cannot support native strip normalization, rotation, taper,
height or edge equivalence. They establish that an observed outcome can travel
with the exact values a bounded fixture used, including explicit failure cases.

Real observations would still have material value: a qualified native mismatch
could falsify reconstructed geometry, while agreement could support only the
actually observed configurations and branches. A prospective observer must
capture actual region-entry data and complete original point arrays; every
consumed resolution at broadphase, containment, vertex and edge sites; actual
translations/scalars/frame context; lifetime-scoped ancestry; native terminal
edges and branch witnesses. Skipped regions remain NOT_EVALUATED. Traversal return
and final UI unions are inadmissible region verdicts.

A **separate retail implementation brief**, if the maintainer chooses one, must
name exact sites/instruction guards, bounded supported state, native ownership
and repeated-use assumptions, callback costs and retirement/unwind strategy.

separately qualified preservation method. No exception-based mechanism should
be presented as universally state-preserving or non-invasive. Native writers
must not be assumed to honor the fixture's invented lease/version protocol.
The synthetic closure token is a model of ancestry, not an engine-field mutation
proposal. Retail source/probe code is deliberately absent here.

That implementation would need its own offline qualifications and independent
pre-live scientific-value review. A later live brief would separately authorize

opportunistic: no promise that natural preview produces negative multi-point,
vertex, edge or degenerate cases. There is no recommended immediate game session,
