## Evidence boundary and stopping decision

The investigation followed category definitions, native state consumers, production
callers/countdowns, resource interval/modifier dispatch, unit creation and transfer
add/remove/read paths. Aggregate UI labels and guessed setting-interior xrefs
did not supply per-extractor formulas and are preserved as bounded negative
locator results. No missing function declaration, zero xref or checksum was
treated as proof of absent functionality.

Remaining questions have concrete smallest evidence: a numeric tier contract
would need a definition loader/consumer that assigns a tier independently of
models; universal activation would need a bound setter/UI consumer for the halt
state or another distinct predicate; exact output would need the resolved
quantity/interval operands at the mapped creation/update boundary. These are
use-dependent refinements of this descriptive map. New live work, comprehensive
perk arithmetic, organic mechanics and switch distribution would enlarge this
assignment without being necessary to locate the existing inorganic machinery.
