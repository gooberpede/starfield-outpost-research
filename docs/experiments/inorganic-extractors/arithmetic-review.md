receipt was written. Preflight then excluded the entire NAVI type; the bound
was not weakened. That exclusion limits the negative. Exact byte patterns in
CELL/NAVM geometry are not typed FormID references. Full repeat with the

inferred from it. Later direct file-backed constant checks succeed and label

native fallback and writer paths, but did not bind calendar+38 to GLOB 00003a.
The default-20 wording was corrected to hypothetical T=20 after independent
challenge; the native missing-GLOB fallback is 30. Unused guessed function
addresses report NO_FUNCTION_AT; unrelated movie-player neighbors are not
calendar evidence. Missing functions, failed decompilation and search negatives
remain distinct from semantic absence.

Literal rg glob arguments failed under PowerShell and were replaced by supported
directory/glob reads. The UI specialist's unavailable generic Python launcher
and interrupted broad file locator remain disclosed in its local notes; installed
CPython and narrow input readers succeeded. No failed probe is called a PASS.
Initial patch context mismatches made no file change and were corrected.

Important counterexamples are explicit in the report: equal integer UI inputs
can display `1` versus `1.00`; string slicing is not universal numerical truncation;
zero-interval display and scheduling branches differ; fractional registration
quantity can differ from effective displayed quantity; cached eligibility is
not the scheduler's current reason; resets discard overshoot; default ESM
values do not identify current overrides; named chance lists are not an active
extra-item grant.
