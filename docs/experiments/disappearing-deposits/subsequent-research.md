# How deposits can change around an existing extractor

**Subsequent-research synthesis · 2026-11-10 (Australia/Sydney).**
Different complete deposit geometries can occur at the same geographic source
across separate game starts. In the mapped ordinary generation path, competing
requests can supply different inputs to the generator. Together these results
give a plausible mechanism for a deposit to disappear from, or a different
deposit to appear at, an unchanged extractor position. The original D1
investigation remains **PARTIALLY DISCRIMINATED**. Its reported Feynman VIII-b
and Decaran symptoms have no matched incident-time ground or production record.

## Different geometry at the same source

In 30 qualified fresh-process captures of one established **Feynman V** source,
two complete canonical geometry bodies matched the fixed mask-0 reference and
28 matched the fixed mask-3 reference. The comparisons cover all bytes of the
represented geometry body. These are reference matches. The series did not
capture the generating masks, the deciding requests or all effective inputs.
One capture lacked sufficient source-lifetime identification and was excluded
before classification and replaced. The counts describe the qualified series
and give no winner frequency or proof of independent, identically distributed
sampling. Feynman V is a separate case from the reported Feynman VIII-b incident.
[D5AS series closeout](../resource-retained-population/d5as-series-closeout.md)

Under fixed remaining inputs in the native controls, mask 0 produced 74
regions and 193 points, and mask 3 produced 78 regions and 180 points. These
ordinary controls retained the same three resource identities while changing
the complete geometry. Two queries sampling mask 3 produced equal complete
output under that contract. In the ordinary path, the first eligible request
to find an empty entry under the protected lookup for the live source supplies
its own coordinate for raster sampling. One observed competition in B2 had
the earlier unvisited check lose at the protected lookup. Readiness, worker
progress and lock admission can change which request constructs, and winning
the lookup still leaves successful construction subject to later gates.
The fixed-input controls and qualified native continuations explain how
variation can arise without identifying the cause of each retail capture.

## What this could change for an extractor

If new geometry changes which resource intersects the same fixed point,
a scanner or the resource check for placing an ordinary extractor there
could give a different result. An area list can still contain that resource.
A separate native control supplied both Feynman V geometries and found Ionic
Liquids in both area results, while only one geometry admitted it at the
tested point. The restored resource association of an already placed
extractor is separate. The audited ordinary production path can use its
registered resource key when the producer resolves and the other operating
checks pass. No matched retail observation has measured actual output from an
existing extractor across a verified change in geometry at its position.
