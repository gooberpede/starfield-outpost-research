## What changed in the explanation

[C1F](../resource-generation-ancestry/report.md) correctly preserved its executable
default, chance-before-walk discriminator and three failed endpoint alternatives.
C1G finds a different, independently specified input in installed definitions:
`Starfield.esm:00226b0d`, `fInactiveResourceChanceMultExotic`, DATA little-endian
`cdcc4c3d` = binary32 `0.05000000074505806`. The constructor default is
`0ad7233c` = `0.009999999776482582`. Neither is automatically an observed loaded
setting. The new diagnostic was chosen from that exact record before replay;
there was no seed/threshold/weight interval search or fit.

At the candidate source `0:25116:32448:00257f38`, IL cell (10,1) has frozen
draw-times-100 approximately 0.49152764678001404. The installed exotic value
times Cell Exotic Chance 15 gives binary32 0.75, admitting that attempt.
The potentially Copper-blocking additional IL cell (11,1) has draw approximately
10.240686416625977 and remains rejected. This explains why the earlier unit
endpoint failed Copper without implying every higher admission must fail it.
The observed three-point IL path alone does not suppress the Copper singleton.

Equal counts do not mean equal populations. Matching four accepted paths is not
a complete native-population match. This separately named diagnostic changes
only exotic IL entries in the three IL-family source requests. Their other
rarities, resource order, keys, seeds, points, clipping and competition algorithm
are unchanged. All original RG1/RG2 predictions, 967 C1E captures and C1F
counterexamples remain intact. No replacement prediction is adopted.

## Implemented acquisition and remaining distinctions

The separate owned C1E controller extension uses four guarded hardware execution
sites: generator entry, ordinary resource CALL, first chance branch and provider
return. It records source and manager memory, raw owner/BIOM/source descriptors,
selected DNAM, family root, raw selected RSGD prefix when available, mask,
resource order, settings payload, actual XMM3 weight and independently observed
XMM1/XMM7 comparison with native CF. The mask branch is explicitly a
**DERIVED static predicate**, not a directly trapped branch. Entry/frame/return
joins and raw bytes are preserved rather than substituting FormID/time pairing.

The collector has no Workshop operand at these sites: it never labels the
generation P3-bound from source memory containing a matching identifier.
Geographic source/owner candidacy and historical P3 consumer ancestry are
separate. Associated-file qualification is inherited from C1D, not inferred
from numeric resource FormIDs. Special/Everywhere calls not joined through the
ordinary CALL remain unbound diagnostics. Prior-region geometry, complete
winning override map, pre-draw seed and historical consumer epoch are null.
Packed key is observed; CRC can subsequently be derived with its owner, but
the post-first-draw MT words are not called the original seed.

The 27-case synthetic suite passes, including paired IL/Cu actual Windows stops
through the real stop-ready selector, partial reads, budgets, no-hit, thread and
nested identity, crashes and durable ACK before termination. C1C 19, C1D 13 and
C1E 32 inherited cases pass. These are engineering results on disposable targets,
not retail or scientific validation. [Review/matrix](review.md) and the exact
local package receipt control final acceptance and remaining limits.

No launch/attachment to Starfield, save/configuration modification, installation,
injection, native byte patch, Ghidra symbol/type/comment/analysis mutation,
staging, commit, push, remote action or publication occurred. Existing installed
MSVC, Python, Git and read-only Ghidra exports were used; no new outside code or
licence basis was introduced. Phase A and independent ACCEPT grant no Phase B
authority. The stopping point is this complete review package and prospective
card, awaiting maintainer review.
