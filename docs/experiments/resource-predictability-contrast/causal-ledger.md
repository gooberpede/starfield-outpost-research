The tested data rule out “two biomes necessarily imply mixed construction masks,”
“one nominal biome guarantees a unique mask,” “same PNDT means same local
pattern,” “same resource options means same geometry,” and “every Workshop
callback must construct its resource source.” They do not rule out a sufficiently
restricted native caller domain making any of these particular sources invariant.
No remaining hypothesis is accepted merely because it is plausible.

The unresolved distinction has two independent tests: statically derive the
source-specific caller domain including virtual neighbor enumeration and exact
sampling; or observe the first admitted query/mask with qualified source/lifetime
and consumer context. A new live observation tests that invocation, not the
earlier Save52 history. Both are more decisive than correlating biome count with
predictability. New live work remains NOT AUTHORIZED.
