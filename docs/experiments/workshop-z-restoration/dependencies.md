## Census-driven alternative writers

The uncancelled native instruction census examines 14,392,060 existing defined
instructions and finds 169 literal `+0xd3]` references. It is a **lead inventory**;
stack offsets, unrelated objects, other bits, aliases and overlapping stores
prevent a whole-program field-write completeness claim. Each relevant family
below was inspected beyond the literal, with direct producer/consumer examples.
The actual 050 call history for these writers is absent; no negative branch
execution is inferred from a failed search.

Writer history is a separate state variable even if every possible writer body
were enumerated. Final position plus an unmeasured flag cannot discriminate a
replacement from one or several signed translations. This is why the closure
does not depend on claiming that every alias or every downstream actor callee has
been traced. For a surviving concrete path, the first missing input is named;
the [acquisition](acquisition.md) targets those producing values and joins.
