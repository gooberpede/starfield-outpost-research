## Supported result and practical limits

The actual command replaces the pinned build's existing GameComment console row,
preserving SFSE's separate BetaComment/GetSFSEVersion row. Original native table
construction, publication, lookup and dispatch instructions support the selected
layout. The command arms a worker and returns; the proposed one ordinary Build
Mode entry is a proposed trigger to test in the pilot. The offline proof does
not establish entry on every opening or reopening. Unrelated queries and preview
operations leave the command armed. A scoped operation with no fresh callback
produces an explicit refusal, never geographical resource absence. If no eligible
operation occurs, the command remains armed until operator STOP.
An overlapping console handler refuses before touching the worker or capture.
A native scope can claim only its own command generation, even if a newer
command is armed before the older callback returns.

Eleven permanent startup sites cover ProcGen destruction, area consumer/callback,
four owner lifecycle phases, the whole established operation and its native
pre-release reference-lease call, plus two source-ending calls: 59 engine code
bytes and eleven 4,096-byte relay pages (44 KiB).
They introduce residual execution and scheduling effects. There are no request,
scheduler, visited, generator, lock-admission or winner hooks, startup resource
scan, generator call or forced refresh. Startup sole-thread admission can delay
loading; STOP remains available without a healthy elapsed-time cutoff. Native
console publication, one registration task and service exit precede COMMAND_READY.
No assumption of SFSE task main-thread affinity is used.

Normal capture reads under an actual foreign ProcGen reader and copies every
occupied holder, resource, region and ordered point into owned buffers. The
callback takes nonblocking shared observer admission before any borrowed owner or
map read. Whole native lifecycle phases wait out existing shared copies, publish
an active count, then release the observer gate before running their originals.
This avoids a phase-to-phase lock inversion. The actual entry epoch precedes
native ProcGen selection, and the copied current binding must match before holder
or map reads. Checked reads, overflow checks,
measured capacity and two-pass preflight preserve explicit failure. The original
consumer returns through its reader release before normal file IO. Original SEH
exceptions propagate; the failure-only tombstone reports release UNKNOWN and
disables further capture. No game termination, exception suppression, hot unpatch
or automatic retry is implemented. The [lifetime proof](d5ar-lifetime-admission.md)
distinguishes actual exclusion from the superseded epoch-only detector. An
abnormal original phase disables borrowing, with failure-only accounting for
an already accepted command. The unsupported copy-to-phase self-upgrade can
propagate a private protection exception; later native phases forward normally.

Source fields have a separate synchronized lifetime contract. Before either
native source free, the observer permanently records the existing address
operand under an exclusive owned gate, then releases that gate before forwarding
the original free. The complete fixed source group holds shared admission and
refuses any retired/reused address or recorder coverage failure. Those refusals
preserve healthy holder geometry. This bookkeeping allocates owned set nodes
and changes timing; it adds no source-construction or generator hook. The
[fresh-process preload proof](d5ar-preload-history.md) and complete ending graph
are mandatory history premises; current-map membership alone was insufficient.
Copied bytes do not certify later source allocation lifetime.

The selected reference identity is copied under the native resolved-reference
lease before its original release, and linked to the same logical established
operation. Post-release allocation continuity, unique player membership and
complete physical-area coverage remain UNKNOWN. Unleased nested reference,
base, cell and translation-vector traversal was removed. Unrelated, unknown and
empty resident entries remain in the output. Neither
nonresident sources nor their deposits are fabricated. The [identity record](d5ar-identity-investigation.md)
retains actual caller and retirement graphs, adverse old-map cases and remaining
binding/area limits. The [source-planar proof](d5ar-source-frame-proof.md) establishes
a separately named represented-coordinate basis conditionally on those source
lifetime premises; it does not replace the old consumed-generation-frame contract.

The original AC05 gate additionally requires effective generation-input
equivalence. Proving a common coordinate basis and equal represented bytes does
not establish all C1 clipping, settings, key, order or extra-pass premises in
retail. Independent review explicitly keeps this gate INCOMPLETE; the active
investigation has positively recovered final source dimensions, ordinary
stitching initialization, definition-file dependencies and the reset-to-reload
route. It also recovered the [144 ordered keys and source BIOM](d5ar-key-input-proof.md)
under ordinary initialized premises, the [empty C19B list](d5ar-atmosphere-native-proof.md)
under the pinned native definition route, and bounded exclusions for
[saved component restoration](d5ar-saved-components-proof.md). No historical
per-use settings, loaded-raster identity or immutable component input record
is supplied by the snapshot format. The classifier's MATCH labels are exact
content events; they do not infer a historical mask. A0's earlier direct mask 3
observation is independently recorded and remains valid within that capture.
