## Native geometry and controls

`d5u_native.py` adapts the owned D5T harness at the starting HEAD. It loads only
explicit PE-backed pages inside a disposable Python process. Original RNG, cell,
chance/walk, clip, competition, bounds and append/deep-copy instructions execute.
Callbacks supply native-validated keys, preallocated resource collections and
successful storage; temporary deallocation is suppressed inside this process.
The native competition consumer's pinned host CRT `atan2f` is wired explicitly.
These substitutions qualify an execution envelope, not a full loaded game.

`native05/` is the final primary run. Every complete native point array and bound
matches the independent owned planar model; final variants repeat exactly.
Native endpoint/far/near-segment-edge probes challenge rendering geometry.
Additional cross-population native membership tests find an actual resource/point
with opposite hit results for every unequal variant pair. The exact pair/point
receipts are in `population_discriminators`, so counts alone are not the proof.
U01 mask-1/3 and U26 adjacent-weight controls instead preserve complete equality.
Allocation failure, prior source history, nonordinary products and retail
consumer correspondence are outside the executed success envelope.

Earlier `native01`–`native04` are preserved qualification checkpoints. The first
key wrapper failed to locate its local import; a later UTF-8 edit broke a source
replacement expression. Both setup failures were corrected without native fault
suppression. Missing key receipts also caused a map build refusal; later map
reproduction against an intermediate regenerated catalogue was invalid until
the matching final data were rebuilt. These are engineering failures, not
scientific negatives. No earlier failed attempt substitutes for final evidence.
