## Stop, escalation and resumable state

On refusal, stop only the affected workstream immediately, preserve exact message/attempt/action if exposed, do not retry/rephrase/disguise/partition it, and do not automatically resume. Continue only genuinely unrelated authorized work. The missing historical primary refusal text is an input request if needed for adjudication, never a basis to probe triggers. Resume point is frozen checkpoint 623b49c plus the C1 matrix and exact evidence manifest; the smallest later request names the blocked edge/action and permissible evidence-only alternatives already evaluated.

On missing source lifetime/synchronization proof, do not dereference a selected pointer, assume Grid protection, infer geographic identity, or qualify a chain. On an existing contrary free/writer path, reopen affected Q1/Q2/Q4 coverage before adding instrumentation. If existing evidence suffices, do not demand fresh native work merely because the old report said coverage unfinished. If it does not suffice, record exact absent function/edge and why each safe existing route cannot answer it; uncertainty alone is not terminal BLOCKED.

On failing tests or final review, retain FAIL/NOT TESTED and return REWORK under the original contract; a successful isolated fixture is insufficient. On byte/pin mismatch or lost original evidence, stop the affected conclusion and request the exact original input rather than replace the pin. On future disk/guard/worker/integrity failure follow only the separately approved control/recovery plan. Slow operator response, elapsed time, evidence volume and missed cadence alone are not failure. No arbitrary session/record/byte cutoff, automatic extra travel/retry, hot unload/unpatch or save restoration is introduced.

This planning decision does not show native continuation universally impossible or safe. Existing-evidence and ordinary engineering work remain viable; native work is a conditional dependency, not a predeclared permission finding. All original D5AB mandatory criteria survive intact.
