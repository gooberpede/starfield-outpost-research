# D5AE normal-play predictability

**Content and registration order do not uniquely predict the constructing query
under the defined ordinary multi-worker conditions. Actual ready-task progress
and protected-map order are required inputs.** This is a controlled scoped
negative, not an estimate of normal retail frequencies.
[Native scheduler](d5ae-scheduler-causality.md), [winner model](d5ae-winner-model.md),
[tests](d5ae-methods-and-tests.md).

## Defined ordinary initial conditions

The independent D5S/D5W contract uses Feynman V body `0x0005e0de`, source
`0:37536:20928:0029d20e`, descriptor anchor `(37536,20928)`, focus/centre zero,
ordinary mode 2, valid owner/component, stable discriminator and source lifetime,
main-file definitions/default settings, ready source/file/placement prerequisites,
successful allocation/copy and a healthy shared pool with at least three workers.
Target coordinate/layer/density keys, visited and source-map state are cold;
metadata and queue capacity can be resident. It is a legitimate ordinary native
starting contract, not a reconstruction of all B2 arrival operands.

Same-prefix native continuations choose different actual claims. Owner-back
construction uses `(10,11)` and mask 3; peer-front uses `(-2,-2)` and mask 0.
The precise unconstrained edge is which runnable worker makes progress through
dispatch/claim and the target provider before a competitor does. The shared
prefix has no native join requiring the owner continuation to finish first.
Pending layer preparation keeps an otherwise independent layer candidate from
invalidating either witness; it is not omitted from the proof.

The earlier target registration `(-2,11)`, index 419, precedes mask-0 index 833
by 414 registration steps. That gives opportunity but no minimum elapsed time
or completed worker service. Native incremental batches demonstrate different
queue extrema; merely labelling a schedule FIFO or LIFO predicts them wrongly.
Readiness delays before arbitration can change the admitted competition.
Post-authority raster loading cannot reverse a granted miss.

## Falsifiable predictive use

Given full actual queue/readiness/worker progress and map state, apply the
native claim rules, then select the first eligible protected miss. B2's actual
miss/store/hit operands predict retained reuse by 3837; swapping only the two
protected acquisition orders in a fresh, valid synthetic control swaps authority.
The native continuations independently show the scheduler permits alternatives;
the synthetic swap is not offered as that proof.

Without those runtime variables, report a set of feasible winners under the
specified contract, or a bypass/no-construction result for warm state. Do not
derive the constructor from source anchor, beacon position, first registration,
first visited check, worker identity alone or an unmeasured mask-area ratio.

## Minimal future discriminatory measurements

No new live run is needed to establish the scoped failure of unique content-only
prediction. Measuring a **usual** winner requires independently prepared retail
episodes and cannot be recovered from these offline controls. This is a proposal
only; it grants no deployment, instrumentation or live authority.

For each episode, bind executable/content/observer/save/configuration identities,
source allocation/publication and owner/descriptor, actual empty target state,
request-key reuse, dependency transitions, task publication and worker claim,
original query, visited outcome and protected miss/hit/generator/sample/store.
Record QPC before queue admission and correlate task identity across boundaries;
record lock acquisition separately if lock waiting is to be measured. Capture
pre-travel demand as well as destination demand. Distinguish source/owner reset,
retirement and aggregate reuse so warm reuse is not counted as a new trial.

The smallest mechanism discrimination is to observe which candidate becomes
ready/claimed before the protected miss, distinguishing readiness delay from
claim-to-provider overtaking. Repeated independent episodes would then estimate
a distribution under declared conditions and disclose instrumentation effects.
No arbitrary episode quota or unapproved observer implementation is prescribed.
GC-31 and the broader D5R questions remain open.
