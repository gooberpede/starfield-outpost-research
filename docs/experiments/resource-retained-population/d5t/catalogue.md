# D5T candidate catalogue and outcome proof

[Candidate CSV](candidates.csv) enumerates all 196 support queries. Its outcome
column is conditional on winning. Two rows carry the actual D5S scheduling proof;
194 retain individually unestablished arbitration. No unproven candidate is
silently excluded. [Report](../d5t-report.md), [sources](../d5t-sources.csv).

## Admission and exhaustive support

A is the set of original integer queries that, in an execution satisfying the
unchanged D5S normal-arrival contract, emit this same target source and reach
its first successful exclusive source-map miss with valid source/component/files,
target unvisited, successful allocation and no earlier target constructor.
Registration, readiness, claim and effective miss are different steps.

S is `[-2,12)²` in the manager's original local-cell frame. The source's nominal
anchor is `(0,0)`, extent 10×10, padding/merge 2. Grid interior, edge and corner
construction installs a source only in that finite source-plus-padding rectangle.
Neighbor/corner combination may displace a contributor, but does not enlarge
the installed support. The primary lookup uses the original query, subtracts
the Grid origin and bounds-checks it; source enumeration returns only that cell's
contributors. Both density and layer provider routes forward the original Int2.
Therefore A is a subset of S, including for the direct cell route.

Decisive preferred static VAs: Grid lookup `0x140985870`; edge installation
`0x140985900`; corner installation/combination `0x140985c50` and `0x140986080`;
corner retention `0x140988670`, enumeration `0x140988760`; provider lookup
`0x14079f92c`; original-query forwarding `0x1407a1a3c` and `0x1407b526a`.
The fixed constructor initializes both edge dimensions at Grid `+0x50/+0x54`.
The [source ledger](../d5t-sources.csv) pins complete function exports and D5S's
source/initialization proof, including the negative layer-root control.

All 196 support coordinates occur in the qualified density registration, with
distinct packed request keys. Fresh native query conversion checks every one:
face cell equals `(37536+X,20928+Y)` on chart 0. Fresh raster sampling evaluates
both qualified fused/unfused arithmetic branches and finds the same masks.
M0 consists of X -2 through 11, Y -2 or -1; M3 consists of X -2 through 11,
Y 0 through 11. Queries outside S are excluded because this target is not an
emitted primary-cell contributor there; their masks need not be sampled.

## Input factorization

Provider `0x14079f860` selects the source through the original query. For that
same selected source it computes generator origin from source `+0x10/+0x14`
minus padding `+0x20/+0x24`, multiplied by 100. The query-relative cell result is
a separate local used by later density work. The origin passed at
`0x14079ff18` is source-derived, not that query-relative local. The same call
converts the original query through `0x14078d660` to geographic sampling inputs.

Ordinary constructor `0x14079b520` uses those geographic inputs at
`0x14079b8e8` to sample `0x142339340`; the latter returns its low nibble at
`0x142339428`. Through the ordinary loop ending at `0x14079be20`, geography
influences only the ordinary rarity weights. The later geographic cosine use
belongs to the separate Special branch. Source dimensions, origin, clip, owner,
selected effective DNAM and descending resource order are independently fixed.
The source-wide loop `0x14079c470` supplies resource/X/Y order to native cell
generator `0x14079a330`. The generator key helper uses source-origin-plus-cell;
it does not use the constructing query. No changing map address is used as seed.

Thus G(q) equals O0 on `A intersect M0`, and O3 on `A intersect M3`. There is
no third mask in S, hence no third effective ordinary vector. No generator
random state is inherited from a preceding query: CRC/MT resets per cell call.
Actual ordered competition and successful retained copying were executed for
both complete populations, not inferred from vector differences.

## Nonempty and different classes

D5S's single normalized registration prefix admits the peer continuation
`(-2,-2)` in M0 and owner continuation `(10,11)` in M3. Its native dispatcher,
completion-marker controls, corner permutations and selection-to-exclusive-miss
proof establish feasibility. D5T rechecks their coordinates and raster samples.
The other 194 candidates are classified if they win; exact scheduling eligibility
is not required to distinguish further outcomes because each has the same
complete effective operands as one of these two witnesses.

O0 has 2/15/57 regions and O3 has 25/35/18. Complete point arrays and bounds
match independent geometry; the O3 repeat is identical. D5S's strict native
spatial Ionic Liquids witness near `(-20.3881,-6.49579)` is present in O3 and
outside both O0 Ionic Liquids bounds. Later resources retain their separate
collections. D5T's complete populations preserve that discriminator. The two
outputs therefore differ materially in surviving spatial geometry, not only
in internal arrays or weights.

This proves exactly two outcome equivalence classes on A. It does not claim
that all 196 support queries are feasible winners, that 168/196 is a retail
frequency, or that paths bearing the same resource occupy disjoint areas.
