## Byte and coordinate contract

The native planar source frame uses descriptor anchor `(37536,20928)`, source
origin `(-200,-200)`, clip centre `(300,300,0)` and half extent `(700,700,0)`.
These are separate from the original Int2 and saved beacon position. Each run
executes 144 source cells per resource in native resource/X/Y order. Geometry
includes resource FormID, every 24-byte represented region header, point count
and every ordered 16-byte point. The representation excludes allocation pointers
and spare capacity. No sorting, deduplication or tolerance conceals differences.
The semantic point/bound oracle independently packs all binary32 coordinates;
header equality alone is not used as a geometric oracle.

## Equivalence and counterexamples

For this fixed main-file source, D5AF positively resolves absent Special and
Everywhere candidates. D5T's factorization and that exclusion make different
same-mask original queries equivalent for this complete fixed-source ordinary
output contract. The controls supply the query conversion; they do not execute
the outer generator to re-prove all preconditions. D5AG does not read B2's
unrecorded losing-query raster or effective component by analogy.

The full generator also reuses the original geographic query for Special
sampling when applicable. Equal low nibbles are therefore not a general proof
of full-generator equivalence. Fix source/frame, owner, cell-key/CRC inputs,
ordered effective definitions, DNAM, settings, raster/readiness and applicable
extra passes before claiming complete equivalence. D5U's separately qualified
source with masks 0/1/3 and 69/77/75 regions preserves the counterexample to a
universal two-outcome bound. The [D5T report](d5t-report.md),
[D5U report](d5u-report.md) and [D5AF extra-pass qualification](d5af-geometric-reproducibility.md)
retain their original scope and failures.

Changing an earlier resource's weights can alter a later resource's retained
paths even if that later resource's own weight is unchanged. This is an existing
native generation dependency, not a new investigation of physical overlap.
No deposit-overlap acceptance criterion or task is introduced.
