# D5AF candidate-based runtime discriminators

**A later observation proposal is scientifically motivated by specific native
admission candidates. It must measure their deciding edges, rather than only
collect additional winner masks.** This document authorizes no implementation,
deployment, instrumentation change, launch, attachment, travel or new capture.
The [pre-lock graph](d5af-prelock-causality.md) and
[candidate table](d5af-stabilization-candidates.md) define the hypotheses.

| Candidate / fixed premises | Predicted discriminator | Minimal correlated measurements | What would disprove the explanation |
|---|---|---|---|
| C1 geographic head start; same ingress, descriptor, cold keys and readiness | The predicted earlier geographic class must be admitted and complete arbitration before alternatives catch it. | Request coordinate/task identity at registration/publication, actual dependency-ready boundary and target protected miss. Observe competing eligible classes, not just the winner. | The predicted head-start class is absent, later-ready, or repeatedly overtaken under the claimed conditions. A step-count lead without service progress does not verify the prediction. |
| C2 readiness/rank; fixed task graph and effective rank | Later-ready work cannot have executed before its required dependency transition. | C3 worker locality; fixed publication sequence and pool | Owner/peer/shared route predicts the claimed queue endpoint; changing activation/service can change the first target candidate. | Callback/task identity, pool/TLS context, owner/peer route and claim, original query, provider invocation. Same resource list or ordinary mask alone is insufficient. |

The smallest B2-like reversal experiment first needs C4/C5's paired boundaries
and owner-wide contenders. A claim about **normal** preference additionally needs
the C1–C3 readiness/claim chain and independently qualified cold starts. A claim
about complete geometric repeatability needs C7's full population/input contract.
These are distinct layers: instrument only the boundaries necessary for the
particular falsifiable claim. An original execution cannot be replayed merely
by loading the same save and assuming queue state is identical.

No probability or usual winner is computed from the native fixture schedule
counts. If a future scoped proposal is requested, it must name build/sample,
protection, exact hook/breakpoint scope and perturbation, finite scientific
actions, all allowed mutations, evidence flushing, stop/recovery and cleanup.
The existing 40,000,000,000-byte caller-available guard on C: and D: remains;
no arbitrary healthy-run time/output cutoff is introduced. Full-geometry copying
requires its own lifetime/ownership qualification; knowing a field's address
does not make an observer safe.

The smallest missing authority is a separate decision on such a targeted
observation design, or access to an already-existing authenticated trace containing
these exact absent operands. D5AF supplies no live card and no blanket execution
request. The current B2 schema cannot be retrospectively expanded. Static exports,
owned native fixtures and save decoding cannot recover historical callback-return,
pending-register, ownership-CAS or ordinary service-distribution values.
