The classification procedure is:

1. Prove the support upper from actual source/cell dimensions and padding.
   Enumerate every integer query through the qualified transform/raster paths.
2. Intersect with native retention and first-miss feasibility. Establish a
   witness for each possible class, or retain unresolved reachability explicitly.
3. Establish C: source-derived origin and clip, effective ordered resources and

   If any consequential input varies independently, partition by that input too.
4. Equal complete W under equal C gives equal ordinary geometry. Distinct W
   requires native discrimination or a stronger equivalence proof; it does not
   automatically give distinct geometry. Compare the full resource-tagged owned

Thus the number of geometry classes is no greater than the number of complete
weight classes, which is no greater than the reachable-mask count. The procedure
returns an exact classification only when the support, reachability and input

frames, unqualified seams/CPU math, failed construction or other routes. It is a
research decision rule, not an implemented production predictor.
