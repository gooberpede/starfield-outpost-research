2026-11-05, Australia/Sydney. **The examined ordinary Save52 readers do not
supply a serialized PerBiomeData resource-slot image.** The global unit 6
alternatives are concrete typed restores or context reconstruction; its erased
callback is a context-ID remapper. This is a scoped STATIC result for the
pinned native path, not a universal no-serializer claim and not a direct
observation of A0's loaded components. Authored synthesis is REVIEW-REQUIRED;
complete original exports and save evidence remain LOCAL-ONLY.

All addresses are preferred static VAs for pinned Starfield 1.16.244.0,
image base `0x140000000`, executable SHA-256
`7e9adb1414a8e1b325e5e1f097b9b17b78deb7eebeda37a333351a43a60f9d28`.
Type-ID globals, saved IDs, component keys and FormIDs are distinct domains.
Read-only exports use the verified disposable database copy, with no game,
original database, save, installation, configuration, network or Git mutation.
The multi-body exporter selects only explicit existing entries, at most sixteen
per invocation; it does not recursively export callers.

## Meaning for the actual comparison

Cold initialization positively creates and populates the root/slots from
PNDT/BIOM/IRES/RSGD and atmosphere operands before ordinary Save52 load
admission. The examined direct changeform and global restore routes no longer
supply a concrete conflicting serialized slot-image writer. In particular,
the generic-looking unit 6 callback is resolved, and the real atmosphere
access is a read of existing typed definition data. Copy-factory presence
is not evidence against retained startup slots.

This strengthens the ordinary reconstructed-input premise. It still does not
promote the model projection into an observed A0 component dump, certify every
later ambient context transition, or establish full non-mask input equality
without the separate actual selected biome, context/key and stitch premises.
The conclusion is scoped to the examined ordinary routes; unsupported external
callbacks, other builds and arbitrary database alias writes remain outside it.
See the [effective-input gate](d5ar-effective-input-gate.md) and
[normal C19B definition proof](d5ar-atmosphere-native-proof.md).
