Use the [geometry contract](d5ai-geometry-schema.md) and original/raw versus
normalized content identities. Preserve native QPC and thread, source birth,
publication, generation/map, holder/collection, retirement/reset, visited store
and bypass joins. Include actual consumer query and source frame. A raw snapshot
of empty/partial native output is still evidence; it is not proof of intended
successful generation. Refuse unsupported comparison or continuity.

```text
Complete, correctly attributed baseline and return consumer scans?
  no  -> INCONCLUSIVE; preserve narrower observations.
  yes -> Expected population exposed at return?
           no  -> UNAVAILABLE at this measured boundary.
           yes -> Positive lifetime continuity?
                    yes + equal content -> RETAINED.
                    yes + changed content -> CONTRADICTION; investigate.
                    no + proven reconstruction + equal -> REBUILT_IDENTICAL.
                    no + proven reconstruction + different -> REBUILT_DIFFERENT.
```

If retention occurs, report it. Do not engineer reconstruction. One return does
not establish general stability, disappearance frequency or a gameplay anomaly.
Equal reconstructed content does not prove equal scheduling or complete effective
inputs. UNAVAILABLE does not by itself predict a crash or establish no resources
anywhere else. Evaluate any frozen prediction under its unchanged original rules.
