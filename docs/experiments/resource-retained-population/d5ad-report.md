## Connected source-to-generation account

Startup's missing-singleton branch constructs the manager and its registered
ProcGen. An existing singleton can instead survive and be reset. Ordinary full
load has complementary revert/type-3 routes into registered ProcGen clearing;
the false compatibility flag still clears its visited/population stores.
Compatible saved context is therefore not a visited-retention instruction.

Save52's type-3 context key identifies Jemison through the native key unpacking
and independent installed PNDT identity. The loader uses that prefix for a
comparison. Generated-world descriptors and typed world components restore
distinct inputs through their own readers, remapping and queued component
installation. This does not install the serialized comparison prefix directly
as the current manager origin, generate every saved outpost's deposits or prove
an actual Lodge-to-Jemison provider request.

Separate type-7 loading restores the PCM seed and PNDT/world content maps
before the saved type-9 Lodge destination branch. Existing content selections
can be replayed into world activation, and saved placements can be retained,
aged or supplemented before preparation publishes a ready collection. The
sample contains both Jemison and Feynman entries, but byte counts do not prove
which saved row a later target request consumes. This persisted layer does not
restore the ProcGen visited array or its source-pointer resource map.

Selected context/descriptor and loaded definition/component data prepare the
landscape, ordinary/overlay source Grids and MultiFiles state. Source creation
derives geographic identity and visited token from descriptors/content/path,
then publishes into Grid ownership. Source publication and readiness are
different from provider demand, map insertion, raster sampling and geometry.
The [input map](d5ad-input-provenance.md) follows concrete producers and guards;
the [state matrix](d5ad-save-state-matrix.md) separates persisted inputs from
reconstructed/transient/conditionally retained state.

In B2, the Lodge watermark includes 383 source births/publications and no
provider call. Its first reset is 2/3/4. A second reset at 881/882/883 follows
the prefix, then 47 Grid clears advance the observer counter to 207 without
clearing visited storage. Source birth/publication and removal-only operations
preserve the separately derived empty-state anchors until demand starts.
The [chronology](d5ad-load-chronology.md) states both intervals and their native
coverage premises; observer epoch is not a native reset count.

When eligible destination work runs, the provider can bypass through a populated

An admitted miss reaches generation under exclusive protection. Pending raster
