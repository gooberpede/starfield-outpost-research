## Native sufficiency and minimal design

The [pre-implementation decision](d5x-architecture.md) compares narrowed R1,
a purpose-built observer and generator/sampler-only alternatives. A sampler-only
saved-stack witness cannot diagnose bypass, hit, missing selection or skipped
sampling. The chosen fourteen sites include five lifecycle fences, a protected
cold anchor and a scoped normalizer witness. R1's wrapper/region/point enumeration
and ordinary-Grid membership validator are absent. No inherited 256-member
rejection needs increasing or waiving.

Provider entry records signed Int2, ProcGen, aggregate holder, thread and parent
invocation. Each actual cursor selection receives its own token before visited.
Selection does not dereference source memory. Protected lookup copies bounded
source bytes. Converter/normalizer scope captures the engine-local descriptor
and original query copy after engine consumption and before normalization.
A mutable manager pre-copy was insufficient: the fixture changes and restores
manager storage while retaining a different engine-local copy. Actual converter
manager/input operands distinguish primary descriptor input (`manager + 0xc8`)
from the frame-unqualified temporary route (`+0x1c0`). Padding remains raw and
nonsemantic. Generator/sampler wrappers forward actual arguments/results,
including stack arguments and the full return word, interpreting directly observed AL.

The target is `0:37536:20928:0029d20e`, owner/body FormID `0x0005e0de`,
grounded in D5Q–W and source-constructor fields. Geographic key, SFPT/block-slot
ancestry, visited key and allocation identity remain distinct. Same-owner
geographic collisions cannot merge allocations. Prior visual Mask 3 correspondence
is not an oracle.

Cold state is witnessed at reset unlock, preferred static VA `0x14079dec4`,
after map and visited clearing under the same exclusive interval. Matched reset
entry, anchor and normal closeout are required; READY/save loading is insufficient.
All earlier map accesses matter, including hits and invalid contexts. Actual
decision epoch is independent of provider entry epoch; old providers spanning
reset cannot hide activity under an old epoch. Unknown/orphan activity after an
anchor leaves coverage uncertain. Loss or such gaps require a fresh qualified
reset for later first attribution; acquisition continues.

The independent cold-anchor challenge followed module registration, forward reset
iteration and late terrain MultiFiles retention. Landscape is registered/reset
before ProcGen in the inspected route. Late MultiFiles cleanup releases its
cache/`+0x18` object, not raw ordinary/overlay pointers at `+0x20/+0x28`;
that route does not force every anchor to be unusable. Primary exports and fresh
read-only disassembly/method receipts are in `.local-work/d5x/cold-order02.*`.
Actual later invalidation still rejects an episode; retail availability is untested.

## Integrated qualification and limits

The builder uses installed MSVC/MASM/SDK without downloads. Fresh installed
EXE/ESM/PlanetData/SFSE/loader and database identities are retained in
`.local-work/d5x/identity05/identity.json`. Build24 rechecks its identity04 input
pins before/after execution. The same packaged DLL, patch assembly, bridges,
queue, worker and independent reader run in disposable Windows hosts. Null SFSE
API, wrong runtime/host and mismatched native guards refuse admission.

Original fill/edge/corner/append instructions execute from a disposable RX page,
feeding their actual cursor chunks through selection hooks. A supplied spare
chunk prevents allocator execution. Map, lock, manager, reset and sampler state
are explicit fixtures, not whole-engine emulation. Synthetic request/mask pairs
test linkage, not the real raster at those coordinates.

Each fixed record is 312 bytes versus R1's 1,528-byte geometry payload. Fourteen
versus eleven sites alone proves no throughput improvement. Native sentinels
check volatile GPRs, XMM0–5, flags, argument/result forwarding and thread LastError.
Whole-fixture timing includes observer, worker and scheduling effects, not isolated
hook cost or worst-case retail timing. General asynchronous unwinding is unqualified.

The bounded queue/retries permit ordinary loss without retiring acquisition.
Worker snapshot drains prevent sustained production from starving flush/health/STOP.
Raw flush precedes identity-bound ACK flush. READY/challenge ACK publish through
flushed temporary files and atomic moves, with separate startup/request nonces.
STOP waits for every event producer, including orphan/diagnostic producers, and
leaves resident inert wrappers. No total event/byte/session-duration quota is
imposed. Both 40,000,000,000-byte disk floors remain active. `complete_session`
means intact transport and finalization of admitted records; saturation may still
have counted native loss. The reader materializes input and is not qualified for
arbitrary evidence sizes. Missing records never prove absent native activity.

## Preserved failures and remaining scope

Build01 failed a standard include; build02 refused non-sole-thread installation.
Source-changed development builds are not final qualification. Build10/11 failed
request reading after READY, including after atomic publication was introduced.
The bounded Win32 reader fixes the observed failure; the inherited stream-reader
cause remains UNKNOWN. Checkpoint 3's partial-write explanation is superseded,
not established. Failed task-owned development processes were explicitly stopped
with receipts preserved; no game process was touched.

Build13's recovery probe preceded writer drain and failed its chain oracle.
The fixture now waits for durable quiescence and measures bounded batches.
Later LastError, prior-hit attribution, sequence-wrap, actual consumed-descriptor
and reset-order findings required correction. All earlier packages/receipts remain;
green subsets do not qualify build24.

No intended/preferred mask, complete population, later cache reuse, extractor
result, saved geometry or bug cause is established. B1 may observe only some
boundaries or no cold anchor. Unexpected aliases, missing coverage and unreadable
context yield weaker results without forced clearing or automatic retries.
