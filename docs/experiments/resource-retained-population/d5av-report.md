## What actually survives

The owning Grid holds the geographic source allocation. Registered ProcGen
holds a map keyed by the full source pointer, with a separate reference-counted
holder and nested resource collections. A separate array tracks visited tokens
derived from source content. A source's key, frame, lifetime and token are
different evidence. A Grid reference or raw cell/file alias does not pin the
source allocation. A collection reference can delay final free after map erase
without keeping the source resident or restoring the map entry.
[D5AH ownership](d5ah-lifecycle-matrix.md#owners-readers-and-release-boundaries) ·
[D5AJ exact erase](d5aj-invalidation-matrix.md#positive-ownership-proof).

1. **While the source stays live**, a protected consumer can traverse the
   current map. This is how the inspected Workshop area refresh can reuse
   contours. A cached list of admitted resource identities can also survive
   separately. Reopening Build Mode does not establish that the refresh or
   Workshop initialization ran. At the provider, a matching visit skips lookup
   entirely. An already-admitted unvisited request can instead hit the map
   under exclusive protection and skip generation, as B2 shows. Upstream,
   detached density can reuse its aggregate and skip the provider. The mapped
   layer route holds a manager reader through preparation and provider use,
   with its own admission gates. A prepared layer or aggregate alone is no
   source-map witness. [D5AH readers](d5ah-lifecycle-matrix.md#owners-readers-and-release-boundaries) ·
   [D5V decision path](d5v-lifecycle-consumer-map.md#construction-and-ownership).
2. **When the source is retired**, the ordinary overlap-loss branch frees its
   allocation and erases any matching pointer-map entry. Clearing its owning
   Grid has the same target effect. Neither operation locally clears the
   visited array. If a later allocation for that geography supplies the same
   surviving token, the provider can bypass even with no holder. This is a
   supported native counterexample to “a return always rebuilds,” with no
   qualified ordinary retail trip shown to leave this exact state.
   [D5AH transitions and controls](d5ah-lifecycle-matrix.md#transition-matrix).
3. **After a broad reset or a fresh owner**, eligible demand can construct.
   True and false manager reset variants dispatch registered ProcGen clear
   through module slot `+0x18`. The pointer map and visited storage clear
   under exclusive protection. The source follows its Grid owner; the
   manager's allocation can survive reset. Process exit ends all old process
   lifetimes. No demand, earlier bypass, missing valid input, or failed
   allocation/copy can leave geometry absent or partial. The map hit or token
   append alone is insufficient evidence of completeness.
   [D5AH gates](d5ah-lifecycle-matrix.md#reset-and-return-predicates) ·
   [D5AH release](d5ah-lifecycle-matrix.md#native-release-addendum).

To establish uninterrupted **complete** population and actual reuse across
an action, bind the source/body and consumed frame, process and manager/ProcGen
lifetimes, birth/publication in the owning Grid, pointer-map owner and all
collection-content lifetimes to complete representations before and after.
Account for relevant fences and transport loss, including potential address
reuse. Record a protected hit or actual map consumer for the same target,
and the absence of a new target construction/sample within qualified coverage.
Unchanged geometry without the lifetime history admits the D5AK alternative.
Equal pointer/slot values, token equality and observer epoch alone are weaker
observations. A protected hit can also reuse a partial holder.
[D5AJ source-specific proof](d5aj-invalidation-matrix.md#positive-ownership-proof) ·
[D5AK geometry contract](d5ai-geometry-schema.md).

For travel, manager component release can reset when the current owner is
nonzero and the qualifying current component differs from the supplied
component. Owner installation can choose true reset for an incoming zero
owner, a same-owner component mismatch, or an owner change from existing
nonzero context. Same-owner/same-component installation can still take false
reset. The separate cell route can return early for the same cell with force
zero. Its reset paths require the manager mode and selected-reference guards,
then branch on the qualifying cell flag or the fallback setting. These
predicates concern the affected native receivers. The action label does not
supply their actual operands. [Exact receiver and cell predicates](d5ah-lifecycle-matrix.md#reset-and-return-predicates).

The mapped fast-travel route provides a positive link to these alternatives.
The admitted pending transition calls context processing at `0x141a21d33`.
In `0x1417df210`, a resolved matching component, nonzero manager context and
mode greater than 1 can exit before owner installation. In the resolved
component branch, a component mismatch or zero current context can take the
coordinate-bearing preparation call at `0x1417df4e2` when the destination
coordinate comparison selects it. Preparation `0x14078b030` can then reach
the owner installer at `0x14078b3f4`. The context processor's alternative
branch compares its computed context to manager `+0x80`. A mismatch with
the null result guard from `0x142116840` can reach true reset directly at
`0x1417df632`. A match with a valid focus object and the additional focus
guards can call the movement update at `0x1417df6b9`. An early exit from this
processor does not exclude later cell or focus transitions. The compiled
edges explain why a local hop can have distinct consequences and why the

## What a save carries and when a sample can change

Ordinary type 3 stores context comparison data and generated-world
descriptors/components. Type 7 stores the PCM seed and separate PNDT-keyed
content and world-keyed placement maps. Save52's audited type-9 destination is
the Lodge **interior** on Jemison. The ordinary load restores PCM before
destination preparation. Resolution, queued work and later placement reuse or
refresh still matter. Ordinary full-load revert and type-3 load have
complementary clearing branches under a stable setting, so a compatible
context comparison alone does not preserve the old map. The positive
writer/reader and reset evidence classifies the live map, visited array and
generated contour collections as transient for these audited paths. It does
not establish an exhaustive absence of any possible derived representation
elsewhere. Writing the audited save channels alone supplies no reset witness.
[D5AD framing](d5ad-save-state-matrix.md) · [D5AD load order](d5ad-load-chronology.md).

Placed references and Workshop producer records can preserve resource
association and bookkeeping through separate serialization. Successful
remapping, re-registration and current operating gates still matter. A
resource-keyed producer row is no evidence of saved contours or of output
across a geometry change. [D5AH producer serialization](d5ah-extractor-continuity.md#what-is-serialized-and-reconstructed).

With a valid target Grid/source/biome and ready inputs, the first eligible
unvisited protected miss can run generation with its own original request's
raster sample. A fresh request can reproduce the previous effective sample.
D5AK directly records this from two distinct coordinates. Fixed-input
native controls also produce different full geometry for consequential mask
changes. D5AS compares complete source-planar geometry against those qualified
reference classes without measuring the original winning request or mask in
each snapshot. Its two classes establish different cold-start results, with
no isolated cause for an individual historical result. D5AT coordinates at
other sites bound conditional inputs only. They supply neither completed
visit cohorts nor chances of a different outcome.

For a player, staying in the same live coverage is compatible with stable
deposits. A return with identical deposits can still have rebuilt them.
Saving preserves inputs and objects through the audited channels. The pinned
D5AL same-save comparison rebuilt equal geometry. The two D5AS classes arose
under the reported same-save visit procedure, with individual loads and
effective input equivalence unverified. A save alone gives no guarantee of
equal contours after arrival. Same planet, same system and a familiar menu are insufficient to
predict the path. The highest-value unresolved contrast is one same-area
return with a measured target lifetime and first return decision. It is
optional at this conditional scope and requires separate authority.
