# D5AG mechanistic discriminators

**Equivalent metadata and a constant seed are insufficient measurements of
independent complete-geometry reproducibility.** The surviving stabilizers are
conditional source metadata, locality/readiness, effective-input equivalence and
retained holders. Their individual predictions must be tested separately.

## Smallest future observation design, if the empirical questions are pursued

This is a measurement specification, not an observer change, executable run
card or request to launch now. Implementation, qualification and separate
maintainer approval remain necessary. Existing B2 cannot retroactively acquire
missing events, and a new session would test a new episode.

First inspect any existing authenticated trace that already contains the named
operands. If none does, observe one exact source through a controlled transition
that distinguishes retained reuse from genuinely fresh construction, then one
return reconstruction with the same effective world inputs. Bind body/system,
source definition/content, descriptor/orientation, owner/component, effective
definitions/settings and input readiness. Record actual retirement and broad
reset separately. Capture complete resource/region/point populations at successful
construction and before consumer use, using the geometry byte/frame contract.
Successful token store alone is insufficient.

For the scheduling hypothesis, capture only the source's eligible contenders
and their causal preparation/ready/claim/admission edges, including alternative
cell/layer demands and other users of the owner-wide lock. B2's two visited
timestamps are not enough. Preserve callback instrumentation timing as a possible
effect on execution. Correlate the first protected miss with effective query and
full population. Do not infer ordinary preference from one outcome or assign
probability by counting possible schedules.

The within-episode contrast is retained holder versus removal-only visited
bypass. The cross-episode contrast is broad reset/load followed by independently
constructed complete populations with equivalent effective inputs. A changed
input is an explanatory contrast, not evidence that equal-input reproducibility
failed. Changed geometry beneath the same extractor would be material, but
unchanged production or resource labels cannot establish unchanged geometry.
No actual gameplay bug is asserted. Physical deposit-overlap tests remain deferred.

Any future run must preserve protected saves/backups, pinned build/content,
both-drive disk floors, explicit scope and stop/recovery policy. This design
does not set an arbitrary scientific event quota, duration cutoff or new live
authority. D5R and GC-06/10/25/30/31 remain OPEN.
