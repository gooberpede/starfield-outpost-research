## Query and native instruction equivalence

The retained D5Q export SHA-256 is
`60cc949338e9e0211b87f56c376e1a057d8b7af2da6f9e34a4ae3e84339f8fcd`.
The [static fact checker](../../../research/resource-retained-population/d5ab_p3_query_join.py)
indexes twenty-three exact instruction facts in `p3-query-join02/receipt.json`.
All following locations are preferred static VAs for image base `0x140000000`,
Starfield 1.16.244.0; they are not host or relocated retail pointers.

The provider saves original Int2 at entry RSP `+0x10`; its RBP is entry RSP
`-0x2c8`. Loading `[RBP+0x2d8]` at `0x14079fea1` supplies that same original
query to converter `0x14078d660`. The converter copies both Int2 components
into stack `+0x60/+0x64` and supplies that copy together with its copied actual
descriptor to the normalizer CALL at `0x14078d6f4`. The returned chart query is
projected by `0x142332410` into provider stack `RBP+0x1b0`, which becomes
generator R8 at `0x14079ff08`. Generator `0x14079b520` saves R8 at entry RSP
`+0x18`. Seven pushes and local allocation `0x2a0` place it at current RSP
`+0x2f0`; `0x14079b8dd` loads that value into the direct sampler's RDX before
CALL `0x14079b8e8`. This is STATIC def-use support for the scoped pointer join,
not a historical observation or a numerical projection executed by this host.

Generator origin RDX points separately to provider `RBP-0x50`. The host uses
distinct original-query, source-origin and geographic buffers and independently
checks their wiring. The observer forwards all six generator arguments but
serializes owner/BIOM/geographic/output operands; it does not serialize the
origin argument. Sample matching alone cannot establish the static dataflow.
The exact input/site guards, native graph and host oracle together bound that
claim. A nearby position or matching raw pointer by itself is insufficient.
