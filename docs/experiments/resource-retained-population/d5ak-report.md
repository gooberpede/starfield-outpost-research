lock covers inherited package pins plus dynamically imported protection,
preservation and archive modules. The old lock and checkpoint remain separately
reproducible; no old output is redefined. Canonical repository paths remain the
execution root; staged snapshots are review material rather than alternate tools.

`d5ak_episode.py checkpoint` performs read-only prefix analysis with the reviewed
D5AJ method. A successful certificate binds plan, process/session, snapshot,
durable core/lifetime prefix and source locks. `departure-check` separately
requires the owned A0 arm and a later fresh worker ACK with intact recorders and
adequate durable coverage. It cannot authorize travel outside a separately
approved finite card. `compare` uses the same source lock and disk protection for
two ordered stopped boundaries in one Episode A session.

The controller limits labels to one A0 and one later A1. Repeated same-label
arming advances the existing challenge and never republishes a consumed capture.
Post-capture checkpoint repetitions read existing bytes only. A1 requires the
baseline departure gate; no other label, automatic retry or extra query exists.

| Condition | Response and rationale |
|---|---|
| Healthy pending arm/ACK or interpretation | PENDING; continue healthy recording and permitted passive observations. No elapsed-time, record, volume or operator-response cutoff. |
| A0 missing, partial, ambiguous or scientifically refused | HOLD departure; preserve exact cause and useful evidence. The operator may choose normal STOP at any time. |

| Timestamp differs with equal protected contents | Record metadata and positively rehash the changed file. Configuration is always content-hashed; qualified unchanged-large-file metadata retains its inherited fast path. |
| Operator STOP | Owned inert STOP, normal operator exit, full postflight and preservation. No game termination, hot unload or original-save restoration. |

The broad lock can refuse the new STOP entry after a source fault. The card
therefore supplies the independently pinned frozen D5AI owned-STOP fallback,
qualified against a deliberately wrong D5AJ lock with original controller pins
intact. A changed trusted controller pin still refuses. If that minimal trusted
closure or authority is unavailable, the operator exits normally and preserves
partial evidence; no failed pin is replaced.

No interpretation failure writes STOP automatically. Classification follows the
actual cause: corrupted transport cannot be waived as scientific uncertainty,
and unqualified scientific identity cannot release departure. If interpretation
never qualifies while recorders remain healthy, the action stays held indefinitely
until the operator chooses STOP; no additional gameplay action is manufactured.
