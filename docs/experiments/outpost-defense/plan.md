# DA1 frozen offline plan

2026-10-19, Australia/Sydney. Governing [brief](../../implementation-briefs/README.md#archive-lookup) (`implementation-briefs.zip :: docs/implementation-briefs/CODEX_BRIEF_SOR_DA1_outpost_defense_attacks_integrity.md`).
The original eight deliverables and sections A–D remain mandatory; no amendment.

Question: what initiates outpost attacks, what defenses change those paths, and
how do constructed objects acquire, lose, recover and retain Integrity?

Allowed actions: read pinned installed EXE/ESM/BA2/development ZIP, existing
read-only Ghidra state, protected historical saves and prior research receipts;
write authored documentation, original bounded research helpers and ignored
local exports. No game, debugger, native invocation, deployment, source save or
database content edit, dependency install, network disclosure or Git mutation.

Routes, in order of information value: shipped script/definition correspondence
for scheduling and Armillary; native UI/target/damage/repair consumers; selected
saved object state and explicit owner joins. Existing P1, E1–E3, S1/S2, CR1–CR3,
R1 and L1–L3 results supply dependency locations, not new runtime observations.
Source names discover candidates; compiled execution and actual fields must
support semantic conclusions. No broad combat or production-tool investigation.

Controls: PSC versus fully decoded shipped PEX, physical ESM field rereads,
native caller/callee and indicator/provider correspondence, healthy versus
damaged saved candidates, explicit construction/owner versus mere proximity,
positive and nonqualifying definition examples. Historical snapshots establish
state, not attack causality or chronological transitions.

Outputs: answer-first report, causal traces and the three required matrices,
exact evidence/source/function locators, verification and preservation receipts,
criterion review, task-only and complete uncommitted-text patches with exact
forward/reverse reconstruction under ignored disposable trees.

Risks: analysis-reader caps, incomplete save grammar, PSC/PEX divergence and
incorrect identity domains. Preserve failures and unsupported branches. All native
locations are preferred static hexadecimal VAs at image base 140000000; file and
decoded-stream offsets and FormIDs are separately identified.

Stop on source-pin mismatch, failed integrity/worker or either drive below
40,000,000,000 caller-available bytes. No arbitrary scientific elapsed/event quota.
Clean temporary decoder scratch through its context manager and retire the owned
read-only reader by sentinel; preserve raw originals and failed receipts locally.

Completion requires every original criterion and independent review against the
brief and primary evidence. Scientific confidence, coverage, engineering checks,
live validation and publication eligibility remain separate. An unexplored lead
or failed parser is not negative closure. New live work requires separate authority.
