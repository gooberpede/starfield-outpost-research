## Unit and mandatory acceptance (unchangeable without maintainer approval)

Each observation records source save/hash, saved reference/token domain,
plugin-qualified base identity (or unresolved mapping), containing workshop/outpost
with evidence/uncertainty, produced resource with evidence/uncertainty, saved
disabled/deleted states, offsets and confidence. Runtime authority is separate.

1. **Inputs/integrity:** inventory both controlled series and Save52; verify
   archived hashes before/after; preserve originals/frozen outputs. Before sizeable
   writes, enforce >=40,000,000,000 free bytes on both C: and D:.
2. **Controlled identification:** source expectations independently from manual
   action report/manifests: zero extractor before S3; one constructed at S3 with
   solar simultaneously; extractor removed S7 while solar/storage/beacon remain.
   Validate action/no-action pairs S2/S2C, S3/S3C, S6/S6C, S7/S7C and remaining
   available controlled labels. Link series tests reload/remapping and retained
   extractor independently of output-link removal. Do not infer resource from labels.
3. **Association:** deterministic reference→base→produced-resource method backed
   by actual definition/serialized/native relationships, independently checked
   against controlled changes and static records. Strings alone are insufficient.
   Report unknowns and counterexamples; distinguish production from deposits,
   power, rates and connected storage. Do not certify load authority or production
   occurring merely from a placed instance.
4. **Mature coverage:** exhaust framed Save52 population for the implemented
   representations; enumerate successes, disabled/historical and unresolved leads,
   with workshop/context evidence and explicit completeness limits. Manual names
   may aid context lookup only, never prove production.
5. **X-Tech:** inspect available DLC/resource/extractor definitions and cited
   sources; verify or label source-reported core cost/nonrefund/deposit exception.
   If no placed candidate occurs report NOT_OBSERVED_IN_SAVE_CORPUS with detector
   coverage, not universal absence. A missing placement is a disclosed coverage
   gap, not an ordinary-association failure.
6. **Tool/tests:** reproducible stdlib/project offline implementation, machine and
   human inventories; regressions for creation, deletion, self/base resolution,
   unknowns, wrong lookalikes and relevant content mapping. Determinism tested.
7. **Review/package:** report, PASS/FAIL/NOT_TESTED matrix, all failed-test history,
   workflow-trial assessment, task-only/complete diffs including untracked text,
   status/manifests/exclusions, whitespace/link/path/content/applicability receipts.
   Fresh independent read-mostly reviewer must ACCEPT or evidence ESCALATE;
   REWORK returns to this assignment, then re-review substantive corrections.

## Negative closure, safety and exit

A negative outcome must falsify a stated candidate rule with independently
supported counterexamples/controls and document tested authorized alternatives.
Ambiguity, failed parsing/search or an unexamined viable route is unfinished.
No universal impossibility claim. Reviewer concurrence required for abandonment.
Continue diagnosis/correction/retesting within this assignment. Genuine missing
authority, inaccessible essential inputs after locator checks, changed protected
hashes, failed disk query/guard or actual session exhaustion triggers evidenced
escalation with preserved resume state; no lowering acceptance thresholds.

Only read game/save/static inputs. Write original tools/docs and ignored local
derivations; no proprietary raw artifacts in Git/review patches. No game launch,
debugger, deployment, save/config changes, dependencies, external contact,
staging/commit/push/publication. Scratch decoder cleanup follows existing reader;
keep evidence local. Independent reviewer tools are available and authorized by
brief section 5; reviewer remains read-mostly and may not accept its own edits.
