## Registration, tolerance and qualification

The primary claim is site/extractor-tied categorical correspondence, not an XYZ
point predicate. Require the saved Workshop/body/parent/base join plus a unique
visual layout confirmed by the operator. Ambiguous identical hardware = UNKNOWN
extractor association; retain a site-only observation if site identity holds.
There is no claim of runtime token resolution from pixels.

For same-view comparisons fix resolution, camera mode, FOV and orientation.
Use the beacon and two fixed landmarks spanning the selected patch. Mark the same
unambiguous feature on each landmark in the original before/after frames; record
both pixel pairs and each Euclidean displacement. Use **no image warping, fitting,
rescaling or camera correction**. Admit the same-view comparison only when all
three direct displacements are at most 3 pixels. A second reader must confirm
the feature choices and recompute the displacements from the original frames;
feature ambiguity or disagreement about admission rejects the spatial comparison.
This is a screen-view repeatability check, not a fitted coordinate registration.
If a compared resource boundary is within 6 pixels of an uncertain edge/occluder,
exclude that boundary. Store original pixels, feature definitions, pixel pairs,
displacements and the independent check. These are proposed acceptance thresholds,
not demonstrated game precision or a native-unit conversion. Changed perspective,
parallax/depth ambiguity or insufficient anchors invalidates boundary comparison.
Readable categorical labels at a positively identified site can still be useful.

Station repeatability qualification: the stationary repeat must preserve the same
three landmarks within 3 pixels and readable labels. A failed registration gets
one deliberate recapture at a better fixed viewpoint; a second failure closes the
spatial arm as INSUFFICIENT_EVIDENCE, preserving site-level channels. This is a
finite method test, not a time/event cutoff for a healthy scientific run.
No point-level match to the frozen Cu radius or an IL boundary is permitted until
an independent world-coordinate registration with a measured error envelope exists.
Saved player XYZ does not supply the ghost/reticle coordinate. No tolerance is
fitted to force a prediction match.
