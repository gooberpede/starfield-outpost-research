Save-only is not rejected for lacking regions: new paired saves could falsify
saved-site stability or expose changed membership/definition configuration.
It ranks second because D1 already found equal saved site fields across historical
pairs without discriminating cache/list alternatives. New random mature-save
scanning offers less information than controlled UI observations.

Manual evidence is technically credible because the eleven F1 views already show
resource-specific colors, selected extractors, overlap/territory errors and distinct
patches. What remains unqualified is repeatable registration and session integrity,
not an invented pixel-to-native decoder. The first pilot explicitly tests those
conditions, allowing a useful categorical receipt without pretending exact XYZ.

Native architecture comparison is in [native.md](native.md). No method is rejected
solely because it cannot answer every causal question. Family A/B observations
retain value even when the decision tree stops at INSUFFICIENT_EVIDENCE for native
input/geometry equivalence.
