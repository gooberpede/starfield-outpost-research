## Input/cache/lifecycle scope

source selection, manager descriptor/owner, resource order/weights/settings and
prior-resource populations can differ despite unchanged saved hardware. A visited
source may have failed construction. Reset, destruction, publication and retained
operation-list refresh are separate events. The first manual pair records actions
and UI only; it must not label those native events observed. Stable observations
and changed observations are both meaningful within that scope. No effort here
