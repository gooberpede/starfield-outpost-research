# Subsystem guides

Start with the question you want to answer. The guides explain ordinary
behavior, its saved-state boundary and known exceptions.

- [Outpost identity and membership](identity.md) follows owner links and construction roots.
- [Planetary location and position](position.md) explains saved sites, frames and terrain cells.
- [Nominal biomes](nominal-biomes.md) explains discrete coverage and its limits.
- [Construction and placement](construction.md) follows catalogue choices through placement and persistence.
- [Resource generation](resource-generation.md) explains why deposits can
  repeat or change and how the result affects building and extractors.

Use the [technical reference index](../reference/README.md) and
[project glossary](../reference/glossary.md) for implementation detail.
The [research roadmap](../research-roadmap.md) covers the rest of the programme.
